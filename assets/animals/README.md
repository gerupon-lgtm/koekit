# assets/animals — 動物の絵

ここに動物（または乗り物など）の画像を置く。両アプリ（ピタリズム／メモリズム）で共通利用する。

## 仕様（配置しやすい形）
- **形状/縦横比**: 正方形 1:1 推奨（カードにぴったり。非正方形でも `object-fit: contain` で縦横比維持・トリミングなし）
- **サイズ**: 512×512px
- **形式**: PNG（背景透過）推奨（WebPも可）
- **余白**: 被写体の周囲に約10%
- **ファイルサイズ**: 1枚 80KB以下が目安（オフライン配信のため軽く）

## 命名（連番）
- `animal-01.png`, `animal-02.png`, … の連番で置く（拡張子は png か webp）
- **メモリズムは同時に最大9枚の別絵**を使うため、**9枚以上**用意する
- ピタリズムは1試行1枚。枚数は自由（「同じ動物ばかりだと飽きる」観点で決める）

## 現状（仮置き）
- 実装は現在プレースホルダを使用中：ピタリズム＝赤丸、メモリズム＝文字 A〜I。
- ここに `animal-01.png…` を置いて「使う枚数」を教えてもらえれば、プレースホルダを `<img>` に差し替えて反映する（コード側で読み込みリストを設定）。
