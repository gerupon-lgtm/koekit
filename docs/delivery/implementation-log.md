- 「レベルをえらぶ」の中間画面を廃止し、タイトルに4レベルを縦一列で配置。はじめから・つづきからを保持し、難易度別のクリア印を表示。高さの小さい画面はロゴ下の説明と余白を調整し、2列にしない。

- 歩数プルダウンは盤面の一辺から1を引いた数まで（3/5/7/9マスで最大2/4/6/8歩）。現在地や障害物で選択肢を変えて正解を示すことはしない。音声パーサ・保存済み指示の数値範囲と、超過しても確定できるルールは維持。

- 次面の開始時に入力メッセージを消去。前の面の「とどけたよ」が残る問題と、練習クリア後に最初の指示が表示される問題を修正。

## 実装判断

- 未コミットの設計・素材を利用するため既存checkoutを使用する。
- 担当境界を新規ファイルで分割し、ルール／探索／保存のAPIを先に固定する。
- メニューは動作中のジントリ等の実CSSを基準に、ロゴ上端58px・主要選択領域229px・タイトル限定フッターをデリバリズム専用CSSに実装する。
- 完了の判断はローカル自動検証と実機受入を分ける。実発話・Android/iOS PWA・音の試聴は未確認のまま明記する。
- やさしいで歩数上限の最後の1歩に配達した場合、未完了なら失敗するが、その実配達をcheckpointに残す。再挑戦は残り0歩を保つ。合意した「最後の実配達と累計歩数の維持」を優先し、追加歩数や以前の状態への巻戻しは導入しない。
- 生成余裕はeasy `ceil(min*0.5)`、hard `ceil(min*0.15)`、最大100試行・Worker5秒を初期値として採用。Lv1は一本道、Lv2から複数経路。実機での適切さは未確定。
- 音声開始は準備中表示、60秒で打切り・タッチ案内・再試行。モデル取得失敗でVoskの初期化Promiseが完了しない実ケースを新作側で処理する。共通音声層には変更を加えない。

### 追加試遊調整：ゴール音のタメ・マイク再試行の間隔

- ゴール直前の250msも既存のキャンセル可能な待機を使用。待機後の最後の移動・荷物の受け渡し・音を同じ処理で反映する。ヘルプを開くなどの中断後に遅れて音が鳴らないことを確認。称号音も同じ待機。
- 共通ヘルプボタンは50pxだが、Deliveryのtoolbarは48px／小画面40pxだった。タイトル以外のtoolbarの最小高さを50pxにし、マイク案内の上余白を8px確保。再試行は44px以上の高さを維持し、説明とボタンをflexで配置。
- 320×568の追加練習でも収まるよう、短い画面の練習説明の余白を調整。失敗表示の小盤面は短い画面のみ110px。文字や操作を非表示にして収める処理は追加していない。
- usabilityブラウザ検証に、案内表示時のヘルプと再試行の8px以上の間隔、ゴール直前の待機と到着・ゴール音の同期実測を追加。Chrome／WebKitの各60状態で縦横スクロールなしを確認。長い指示表・ヘルプ・編集画面の内部スクロールは対象外。実機ブラウザや文字拡大設定での確認は未実施。

### 追加試遊調整：移動中の配置固定

- タメを250msに短縮。最後の移動・受け渡し・ゴール音の同期は維持。
- 実行中はタッチ操作部を消さずに無効化し、盤面のサイズと位置を維持。音声認識休止でマイク再試行案内が消えていた点も修正。練習説明は実行中に書き換えず、クリア時は余白を残して隠す。
- 実行中の指示行への追従は指示表内のscrollTopだけを変更し、ページ全体を動かすscrollIntoViewを使わない。
- 完了パネルは操作欄に重ね、盤面・凡例の位置を維持。次の面への移動は引き続き手動。
- `scripts/test-delivery-stable-layout-browser.cjs`で音声ON・タッチ・音声拒否、基本練習・途中配達の各フレームの盤面・指示表・操作欄の座標と寸法を比較。完了パネルと凡例の非重複、ページのスクロールがないことも確認する。
