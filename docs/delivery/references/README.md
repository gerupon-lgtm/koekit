3状態でキャンバス寸法・体の大きさ・足元の位置・顔・色・向きを揃える。切替時に跳ねたり縮んだりしない。透過背景、縦横比維持、9×9でも識別可能にする。向きの差分を作る場合も荷物の数が変わらないこと。所持数はRuntime由来で上部2枠と同期する。

生成・編集には利用可能な画像生成ツールを使い、まず参考画像を閲覧する。比較シートは最終スプライトシートではないので、そのまま雑に切り取って本素材扱いにしない。共通ズムは既存素材を使う。

音の具体的な割当ては基本設計「キャラクター・サウンド」節を参照。再開時に回収音を再生しない、満杯通過で回収音を鳴らさない、負数表示に警告音を付けない。BGMは未要求。
