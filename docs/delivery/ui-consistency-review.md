## 見つかった差分と修正

- フッターは既に10px・画面下8pxだったが、色が基準と異なった。色を揃え、配置も`bottom`とsafe-areaの明示へ変更。
- 「つづきから」があると称号欄だけ12px下がっていた。通常サイズでは基準位置へ固定。
- レベル文字が18px／小画面16px、左揃え、角丸18px、影なしだった。基準の24px・中央・20px・影と枠へ変更。
- 未クリアも緑背景だった。未達／達成の背景と枠を分け、`completed`クラスと✓を実際の達成IDだけに付ける。
- メダルの色・リボン・輪郭も独自値だった。共通SVGだけでなく装飾CSSも一致させた。
- 自作面だけ配色・ボタンの太さが異なった。共通の背景・操作色・700の文字へ変更。
- フッター固定のためタイトルを相対配置にした際、タイトルがヘッダーを覆ってクリックを遮った。実操作テストで検出し、タイトル時のtoolbarを前面に指定して修正。
