# メモリズム・順番（2026-09-20 実装仕様）

発案者合意の正典は `next-games-discussion.md`。入口は `/kioku/?mode=sequence`。場所モードは `/kioku/` のまま。

## 初版

- 全レベル9マス。動物は重複なしで問題ごとに並べ替える。お手本・回答・答え合わせの間は配置を固定し、常に表示。
- 通常は2〜6手の5レベル。800ms点灯＋400ms消灯。スピードは同じ5レベルを600ms点灯＋300ms消灯で一周する。最後の消灯後に回答開始。
- 最大3問中2正解で即クリア。2問不正解の場合も3問目まで出す（未確定部分の初期仕様）。未クリアは同じレベルへ再挑戦／タイトル。
- 回答の時間制限なし。位置の発話／タップを回答列に追加。同じ位置の繰り返しを保持し、「1・3」のように番号を併記。
- 必要数未満では確定できず、必要数到達後の位置指定は無視。「もどす」（↶）で末尾を取消、「やりなおし」（↺）で回答のみ全消去。問題・配置を保持し、お手本は再生しない。
- 全体を「オッケー」／✓で提出して初めて判定。正解表示は番号＋✓。不正解では「ざんねん」を900ms表示後、正解番号へ置換して「こたえ」と明示。盤面を覆わない。
- 正誤どちらも結果は自動で閉じない。「つぎ」「オッケー」／▶で次の問題かレベル結果へ。採点は一度だけ。
- 音声認識は案内・開始・回答・結果送り・認定書の各区間のみ。お手本・効果音中は停止。マイクを許可しなくても全操作可能。

## 進行・記録

メニューは場所モードと共通のB案（2026-09-20合意）。通常／スピードを切り替え、「2て・3て・4て・5て・6て」の大きな横長ボタンを5個表示する。称号と手数表記を揃え、レベル番号を重ねない。未解放タブは「🔒 スピード」で選択不可。通常全クリアで鍵が外れ選べる。既存ロゴの色味を維持し、ロゴと記録は両モード・両速度で同じ位置に配置する。

メニューは画面高に合わせて各領域を配分し、スマホ縦画面の1画面内に記録・フッターまで表示する。ピタリズムも同じ配置を使用。320×568pxから縦スクロール不要をブラウザ検証。

通常レベルは全開放、全通常クリアでスピードを解放。クリア記録は作品／モード別のlocalStorage。規定正解数に達した時点で保存し、認定書へ進む前に終了しても失われない。通常の称号は2て〜6てマスター、メダルは銅／銀／金／プラチナ／ダイヤ。スピード全レベルでレインボーとスピードマスター。タイトルは直近ではなく最高称号を表示する。

共通 `Progress` は保存失敗時もセッション内で継続し、タイトルに保存できない旨を表示する。音声・個人名は保存しない。最高のスピード称号獲得をマーカーとして保存し、将来の上限拡張でも称号を降格させない。

## 設定画面について

合意どおり初版の着手条件にはしないため、今回は画面を追加していない。`SEQUENCE_SETTINGS` に上限と通常／スピードの点灯・消灯時間を分離した。`sequenceLevels` は最大9手（8レベルずつ）まで生成できる。設定画面は必要になった時に実装する（2026-09-20再確認）。将来の点灯時間設定は通常の75%をスピードに適用する係数連動で合意。変更UI、範囲・刻み、適用タイミング、上限変更時のスピード記録の扱いは後続で具体化する。現時点で利用者が変更できるとは案内しない。

## 実装の境界

- `kioku/entry.js`: URLによる場所／順番の入口。各コントローラは独立。
- `kioku/sequence.js`: ゲーム進行・タイマー・既存音声アダプタとの接続。
- `src/game/sequence.js`: 設定、レベル、出題列、回答列と一度だけの判定。
- `src/game/sequence-phase.js`: 順番専用の回答語彙。既存の単一選択区間は変えない。
- `src/ui/sequenceview.js`: 回答番号と保護者向け開始案内。
- `src/game/progress.js` / `src/ui/achievement.js`: 3つの作品・モードで共通の保存／称号。
