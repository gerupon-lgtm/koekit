## 前提と変更範囲

録音波形は既存の解析用Workerへ渡され、解析終了後にWorkerを終了する。今回整理するのは、その後も編集画面が持っていた細かな音程の数値記録と、別の解析方式の編集候補である。波形の処理、録音時刻、解析方法、保存形式は変更しない。

通常画面と旧編集画面（`?view=editor`）では、編集の「オッケー」が成功した後だけ整理する。詳細検証画面（`?view=full`）は比較と記録出力のため保持する。この承認をフレーズ編集・曲末・Q1／Q2／Q3等の未合意部分へ広げない。

| 操作・状態 | 詳細解析記録 | 音符・曲・編集履歴 |
|---|---|---|
| 通常／旧編集画面の確定成功 | 解放 | 選択中の編集セッションをそのまま保持 |
| 取消、未確定、再生中、入力エラーによる確定失敗 | 保持 | 既存の取消・失敗時の動作を維持 |
| 詳細検証画面の確定成功 | 保持 | 3方式の比較・編集・Undoを維持 |
| 整理後の新しい録音 | 新しい解析を作り、次の確定まで保持 | 採用までは前の曲を保持 |
| 保存・再読込 | 従来どおり詳細解析は保存しない | 曲・音符・伴奏を復元。Undoは従来どおり同じ作業中だけ |

## 実装

- `probe/saezuri/capture-retention.js`：元の結果を変更せず、`frames` を件数の集計へ置き換え、`unquantizedNotes`、`onsetCorrections`、`analysisDiagnostics`、`analysisComparison` を外す。録音時間・入力設定・サンプル数・音符等の概要は保持する。繰り返し呼んでも内容が変わらない。
- `capture-editor-view.js`：`releaseAnalysisVariants()` は成功した選択中の方式と同じ編集セッションを保持し、他方式のセッションだけを外す。選択音符・元の音列・カーソル・Undoを作り直さない。閉じた状態、処理中、未採用、未確定変更ありでは解放を拒否する。方式が1つなら方式選択を無効にする。
- `app.js`：通常画面の成功した確定通知からだけ整理を呼ぶ。診断表示を集計形式へ更新し、同じ取り込みJSONの貼り付け内容と古いコピー用テキストも消す。貼り付け欄へ別の未読み込みテキストを入れていた場合は消さない。入力元の切替時にも取り込みテキストへの参照を外す。
- コピー待ちの間に確定してからコピーが失敗する場合は、最新の記録を作り直して手動コピー欄へ出す。古い音程推移を再表示しない。端末のクリップボード、ディスク上の記録、添付ファイルは変更しない。
- 詳細画面の確定時に、未生成の `imageMode` を参照して例外になる既存箇所を同じ通知処理で修正した。存在するときだけ既存処理を呼ぶ。

JavaScriptが詳細解析への参照を保持しない状態にした。ブラウザが実際にメモリーを回収する時刻・減少量は測っていない。即時に特定量のメモリーが空くという測定結果ではない。
