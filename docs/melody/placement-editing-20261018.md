# 配置したフレーズの派生・差し替え

2026-10-18。今回の承認範囲を専用ローカルブランチ `codex/saezuri-continuation-20261018` に実装。push・公開・デプロイなし。既存の制作・音符編集・鍵盤・鼻歌・試聴・保存・Undoを再利用する。

## 操作と保持するもの

- 配置を選び「ここを直す」。いつもの制作画面で、その一か所を直す。編集前の制作作業とUndoは一時的に保持する。
- 編集後の「オッケー」で元を残した派生版を棚へ追加し、その配置だけを変える。他の配置へ自動反映しない。変更がなければ派生版を作らず戻る。
- 一音ずつ置く「オッケー」はその音を確定して編集を続ける。入力中の音がない状態でもう一度「オッケー」を押すと配置へ反映する。
- 戻る／やめるは配置の編集を取り消す。試聴中なら停止して戻る。編集前の制作作業とUndoを戻す。
- 別の配置で「さしかえる」を開き、使いたいフレーズを明示的に選ぶ。各フレーズを試聴でき、右上の閉じる／中央の停止で止まる。選択は候補で、曲の「オッケー」まで確定しない。「もどす」は候補取消、確定後はUndo。
- 棚の「けす」は未使用のフレーズだけ選べる。使用中は先に配置を外すか差し替える。削除も候補→確定とUndoで扱い、元を自動削除しない。最後の棚項目を明示的に削除しても曲を自動削除しない。

派生名は `A 1`、`A 2` のように元の名前へ番号を付け、同名なら番号を進める。IDも現在の棚とUndo内の記録に重ならないものを使う。familyId、familyName、derivedFromで由来を保持し、元を手動削除した後も命名を保つ。

## 実装と保存

`saezuri/sequence.js` の候補へ `derive`、`replace`、`delete-pattern` を追加。派生は音符だけでなく調・長さ・伴奏等のフレーズ全体を複製する。古い版の候補と使用中の削除は拒否する。`sequence-session.js` は名前・IDと配置ごとの派生を扱う。Undoは以前の配置と必要な元を復元し、あとから棚へ加えた項目も保つ。

`placement-workflow.js` は既存の `CaptureEditorView` を使い、`parkWorkspace()` で元のセッションとUndoをそのまま一時保持する。`app.js` は対応する解析記録・入力元・調号表示等を保持／復元する。別の曲を開くときは一時保持を終了する。

schemaVersion=1を維持し、曲データへ任意の `placementDraft` を追加。元の制作checkpointと配置編集中のcheckpointを分けて保存する。続きからなら配置編集を再開し、「つくりかけをけす」なら未反映の配置編集を捨てる。Undoは従来どおり再読み込み後に復元しない。明示的に空にした棚はsequenceの `keepEmpty` で曲を保持する。旧曲は新項目がなくても開ける。

一括反映・送り・制作支援等は今回へ追加しない。エンディングは[次の工程](continuation-20261018.md)。
