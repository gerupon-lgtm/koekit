# メニューの初期表示・おてほんの操作配置（2026-10-18）

## 原因を確認したこと

サエズリズムは検証用のHTMLを先に描画し、JavaScriptの関連ファイルを読み込んでから通常のメニューへ組み替えていた。全スクリプトを保留するChrome検証で、旧画面が一度見えることを再現した。他の小品にも、レベル選択や共通配置を後から追加する箇所があった。サエズリズムのヘルプは大きさ・色が共通値でも、起動時とトップへ戻る際に自動で選択され、紫の枠が付いていた。

おてほんの「案内をとじる」は `MelodyLearning.end()` を呼び、練習を終了して通常の鍵盤へ切り替えていた。320×568ではドの上端が約776px、停止欄の上端が507pxとなり、初期表示で選べないことを回帰検証で再現した。

## 変更

- 7作品共通の起動用表示 `src/ui/app-startup.js/css` を追加。ロゴと「じゅんび中…」を出し、通常のメニューを作り終えてから表示する。実際の配置は測定できるように維持し、読み込み中の操作部分だけを隠す。読み込み速度の向上を測定した変更ではない。
- 小さな起動スクリプトだけは依存なしの通常スクリプトとして先に実行する。制作・ゲーム・音声処理は既存のES Modulesを再利用する。画面の準備、読み込み、フォントの準備を待つ。失敗時の再試行とトップへのリンク、JavaScript無効時の説明を用意し、15秒を超える遅い通信でも後から準備が終われば表示する。
- 対象はピタリズム、メモリズム（通常／順番）、イロドリズム、ジントリズム、デリバリズム、モノガタリズム、サエズリズム。保存内容・ゲーム規則・音声の受付語を変更しない。
- サエズリズムのヘルプと閉じるボタンに共通スタイルを適用。起動時のヘルプ自動選択をやめ、内部からトップへ戻る際は見出しへ移動する。キーボード操作の茶色い選択枠は残す。
- おてほんの案内は折りたたみと再表示に変更。途中の音・候補・進行を保持し、閉じただけでは通常鍵盤へ切り替えない。
- おてほん中は、この練習で使う「ふつうの高さ・1拍」に絞る。不要な録音・調／小節数・長さの変更を隠し、案内→譜面→その段階の操作→聴く／オッケー／もどすを配置する。通常制作の設定は維持。小さな縦画面ではドレミを2段、横画面では譜面と操作を左右に配置し、譜面全体も枠内へ縮める。
- 共通起動ファイルを配信ごとの更新対象とオフライン用の事前保存へ追加。他作品の既存音声モジュールには更新用URLを付けず、マイク状態の二重生成を避ける。
