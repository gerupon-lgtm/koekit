# おてほんの案内・試聴後の操作・音程の試し音（2026-10-18）

発案者が画像3枚でまとめた指摘と、「このコメントまでをまとめて反映」「押す場所を見た目でも示す」「音程のカードと通常の鍵盤で指定した高さを鳴らす」という依頼への対応。

## 案内と入力の意味

- 「1ばんの音」だけでなく「1ばんの『ド』」のように対象の音名を案内する。選択欄・音の一覧・再生中の表示も、E4などの英語表記から「ふつうのミ」「うえのド」へ変更する。保存する音程番号は変えない。
- 案内が要求する音を、実際の音のIDと現在見えているカード／五線譜に対応させる。以前は選択を求めるIDを表示側が使わず、五線譜へ切り替えると隠れたカードだけに枠が付く場合があった。
- 押す対象は青い枠と目印、選択中は緑の枠で区別する。再生中のカードの黄色と五線譜のピンクは維持する。
- 最初の段階に「①長さ → ②音の高さ → ③オッケー」の図を表示する。候補を確認して決める意味と、確定すると次の入力位置へ自動で進むことを説明する。
- 「？」から基本操作と声の説明を開き直せる。通常のカード入力にも同じ説明へのボタンを用意する。
- 声はONにし、受付表示を待って「ド いっぱく」→候補→「オッケー」。音と長さを一緒に発話する現行仕様を説明する。「レ はんぱく」「ミ ふてんいっぱく」「やすみ いっぱく」の例を載せる。

## 試聴と段階の区切り

- 試聴終了／停止後は「もういちど聴く」「つくる画面へ」を並べる。右上の「とじる」も色と枠で明確にし、再生中の停止は中央を維持する。
- 伴奏つき／メロディーだけは表示切替の横で選ぶ。声の「きく／もういちど」も、選んでいる聴き方で再開する。4小節の見渡しを妨げないよう、下部の操作は2つに絞る。
- 段階完了時は区切り線と完了の説明を出し、「つぎへ：1小節をつくろう」のように進み先を示す。次の音を選ぶ操作とは区別する。
- 声の「つぎ」、既存の8段階、承認済みの15音・伴奏・毎回4分音符4発のカウントは維持する。

## 音程と実音の対応

- ドレミの入力カード、選び直したメロディーのカード／五線譜、高さを直すボタンで、選んだ音色・音程による短い試し音を鳴らす。休みは鳴らさない。
- 試し音は曲の再生とは独立した1音だけを管理する。連打時は最後の操作を優先し、準備中の操作が後から鳴り出すことを防ぐ。停止・移動・非表示・鍵盤開始で終了する。
- 試し音のために候補を確定したり、入力位置・曲・Undoを変更したりしない。カード入力は従来どおり候補→オッケー。鍵盤の練習／タップ録音は既存の押している間の発音を使う。
- 試し音が鳴っている間は認識の受付を一時停止し、既存マイクは維持する。説明画面でも受付を停止し、閉じたら元の条件で戻す。外部への音声送信は追加しない。
