# おてほんと通常制作の伴奏選択を共通にする

## 合意と操作

2026-10-18、発案者の「本番と同じ手順にする」「同じジャンル候補から選ぶ」という依頼を反映。従来のチュートリアル専用「おてほんの伴奏をつける」ボタンと直接の伴奏差し替えを廃止する。

どちらも「伴奏」タブでジャンルとリズムを選び、「進行のおすすめ」で4候補を聴き比べ、「この候補をつかう」で仮の候補にする。制作画面でメロディーと一緒に聴き、「オッケー」で確定する。ジャンルは既存のどうよう・ポップ・ロック・バラードを維持。別のジャンルや進行を選んでも、おてほんの最後の段階を完了できる。

ジャンル・リズム・設定・おすすめは同じDOM部品と処理を使う。伴奏タブでは選択肢とおすすめを直接表示し、鍵盤の練習側では従来の折りたたみから同じ設定を開ける。音符・手動コード・個別に指定した音色を、ジャンルの切り替えで無断に変更しない。

## はずむ8ビート

発案者が「ポップの追加パターン」を選択。合意済みの伴奏を「はずむ8ビート」として本番でも使える共通データへ分離する。

- ルートの8分ベース、小節頭を含むコードの `8,8,r8,8,8,8,r8,8`、既存の電子ドラムを維持。
- FMエレピ、シンセベース、電子ドラム、既存の音量とベロシティを維持。
- 伴奏タブで「ポップ」→リズム「はずむ8ビート」から選択可能。従来のポップや他ジャンルは置き換えない。
- イメージからつくる場合も、ポップの「別のパターン」に9つ目として追加。元の8パターンを維持し、他のジャンルは8パターンのまま。手動のリズム・音色・コード・ジャンル指定は引き続き優先する。
- 既存曲の互換性のため、保存済みのリズムID `tutorial` は保持する。新しいイメージ候補には `patternId: pop-eight-beat` と完全な伴奏データを保存し、再読み込み後も同じ音を再現する。

おてほんを開始した時点では伴奏を鳴らさない。完成形の試聴と実際の伴奏の選択を分け、試聴だけで制作中の曲を置き換えない。完成形のメロディー、途中の休符・タイ、4分音符4つのカウントは変更しない。

## 声とタッチ

声の「伴奏」で同じタブへ、「ポップ」などで同じジャンル選択、「はずむ8ビート」で同じリズム選択、「進行のおすすめ」で同じ候補画面へ進む。「1ばんをきく／1ばんをつかう」から4ばんまでを受け付ける。番号だけの音符選択とは分け、候補画面の外では伴奏候補の番号発話を受け付けない。

候補の再生中は停止・閉じるに絞り、確定はしない。声の受付案内も状態に合わせる。タッチだけでも全操作ができ、録音・ループ中の語彙は従来の範囲を維持する。実声の精度は後述の実機確認に残す。
