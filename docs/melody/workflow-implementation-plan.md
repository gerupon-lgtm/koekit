# 伴奏・録音・保存の実装計画

2026-10-01。既存の作成・編集・解析処理を再利用し、素の ES Modules のまま進める。
作業中のブランチと未追跡ファイルに前任の実装があるため、現チェックアウトで作業し、他作品と共通音声層を変更しない。

## 順序と完了条件

1. 保存・再開
   - `saezuri/song-store.js`: IndexedDB の曲単位保存、上限を1か所で指定、revision 比較、削除後の復活防止。失敗時は既存データを保持する。
   - `probe/saezuri/song-session.js`: 編集セッションの確定部分／つくりかけを分ける。履歴・録音波形を保存対象にしない。空の初期画面と、音符なし・未確定のコード変更は枠を使わない。
   - `capture-editor-view.js`, `screens.js`, `app.js`: 保存状態の通知、曲一覧、再開時の選択、終了前の保存と失敗時の再試行。譜面の常時表示領域を増やさない。
   - 純粋関数の保存資格／候補復元テスト、実ブラウザの再読み込み・競合・上限・削除テスト。
2. 伴奏とコード
   - `music/catalog.js`, `music/accompaniment.js`: m7♭5、バー別コードと分数コード、候補の比較、手修正の保持、パート別音色。
   - `image-controls.js`, `screens.css`: 既存の伴奏タブに小節ごとのボタン、コード詳細は下から開くシート。追加設定はシートへ。
   - コード別音程・8小節・手修正保持・音色設定のテスト。スマホの譜面／確定／停止が押せることを確認。
3. ループと録音予約
   - `audio.js`, `capture.js`, `app.js`: 再生と同一クロックで次の先頭を予約し、4／8小節を録音。録り直し中は伴奏だけ、採用までは元の音列を保持。
   - 境界直前の予約、キャンセル、非表示、マイクOFF、遅延した準備結果の無効化を検証。
   - 音響同期の六つの合図を使う従来方式と、ループ時の推定補正を区別。実機の精度は別途確認する。
4. 回帰確認と引き継ぎ
   - Node 検証を UTC・小分けで実行。Chrome を逐次実行、320／390px と横画面で確認。
   - 実装状態と実機未確認事項を仕様・handoffへ反映。公開／push はこの作業に含まない。

## 追加の合意

- 音符なしのコード変更は、コード確定まで再読み込み復元の対象にしない。
- 保存曲数は将来増やせる構成にする（初期10曲）。
- ハナウタの編集確定時の細かな録音データ破棄は、その部分の実装前に再相談する。今回、確定時の破棄処理は追加しない。

## 作業記録

- 計画作成。既存の編集履歴、音声排他、スマホの画面構成を確認。
- 保存・再開を接続。確定／つくりかけ、同一曲内のフレーズ棚と配置、音符なしの確定伴奏を保存。入力位置・高さ・長さの選択だけでは空の枠を作らない。上限10曲を1か所で定義。曲名を自動付与し設定で変更、一覧で試聴・コピー・削除。
- 伴奏・個別コード・音色を接続。13コード種と任意のベース、開始tick／長さtickの区間を利用。自動比較の試聴は保存対象を変更せず、採用候補を選んでオッケー。手修正と指定パート音色はジャンル変更後も保持。
- ループ・録音予約を接続。マイクと出力を先に用意し、同じ AudioContext の次の先頭を予約。4／8小節で自動終了し、元のメロディーを確定までは保持。負の推定補正と直前指示用に worklet 内で1.2秒の音を一時保持し、終了時に解放（保存・外部送信なし）。従来4小節の六つの合図による実測同期と、ループ時の推定補正を区別する。
- スマホはジャンル・リズム・進行・音色をシートに収め、コード列を8小節でも横送り1段にする。保存表示は見出し内。390×844で主要操作が見え、320px・横画面・文字200%の画面幅を既存ブラウザ経路で確認。
- 新規モジュールの RED→GREEN：保存資格・候補復元、m7♭5／短いコード区間、次ループ先頭と8小節長、保存／コード／ループのブラウザ経路。
- Final review: fresh-context reviewer による読み取りレビュー。空状態への更新漏れ、現在の草稿だけの曲の削除後に残る編集状態、保存失敗後に保存済みの状態へ戻した時の失敗解除、カーソル移動だけの空枠作成を修正。候補取消・最後の音の削除・Quota再試行／取消・2タブ競合・現在の草稿削除・満杯制限を実ブラウザで確認。
- 空の曲で入力位置を動かして確定するケースも枠を使わないよう修正。明示的な休符は位置移動と区別して確定／復元し、Undoはその状態も戻す。おてほんの練習は保存枠を使わず、「フレーズにする」で初めて作品へ登録。満杯でも練習は可能、おためしのコピーと練習の登録は上限を確認する。
- 検証：サエズリズムの Node 194件（UTC、最大5ファイルずつ）と共通ロジック171件が成功。バージョン一致チェック成功。Chrome の保存・コード・8小節録音・画面遷移・通常入力・音符長・既存編集・音声排他・再生追従・解析・カウント・おてほんとおためし・読みやすさを逐次実行。実声の精度・イヤホン／スピーカー／Bluetoothの補正・編曲音色の本採用は未確認。
- Ruling: 前任の未追跡ファイルと他チャットの差分が多数あるため、現チェックアウトで増分実装し、丸ごとのコミットや別チェックアウトへの置換はしない。公開・push・共通音声層・他作品は変更しない。
- Ruling: ハナウタ確定時の細かな録音データ破棄は、ユーザーの再相談指示に従って確認中。音符・伴奏・Undoを保持する範囲を確認してから追加する。この処理と実機品質を完了扱いにしない。
