# ハナウタ v14：仮編集・まとめて確定・音声の上下操作

2026-09-27。ML-T01-v14。v12の音高解析とドンカマ実測補正は維持し、取り込み後の編集を変更した。

## 操作

1. ハナウタを取り込む、過去の数値JSONを開く、または「この音列を編集する」を押す。
2. 譜面・ブロック・一覧で音を選ぶ。「まえ／つぎ」でも選択できる。
3. 「たかく／ひくく」で半音ずつ仮に動かす。別の音を選んで変更を続けられる。数値入力・長さ・位置・分割・結合・削除は詳細欄に残した。
4. 「流れを聴く」で仮の変更を含む4小節を試聴し、「まとめてオッケー」で音列へ反映する。試聴では確定しない。
5. 確定後も同じ画面で編集できる。「ひとつもどす」は確定前後の編集操作を戻す。戻した結果は仮の状態なので、再度オッケーで反映する。
6. 「おわり」で編集セッションを閉じ、Undoを破棄する。未確定の変更があれば、先に確定するか「仮の変更を捨てておわる」を選ぶ。後者でも、すでに確定した音列は残る。

確定そのものはUndoの1操作に数えない。取消は最後の確定状態へ戻す操作で、取消前の仮編集もUndoで復元できる。再生・停止・表示変更・バックグラウンド化だけでは編集履歴を消さない。ページ離脱・再読込はセッション終了であり、作品保存は未実装。

方式ごとの編集履歴は継続保持する。方式を切り替えた場合、その候補を音列へ反映するには改めてオッケーを押す。仮編集中は方式切替・新規取り込み・元曲の置換を抑止する。元の解析診断は書き換えない。

## 音声操作

「声でも操作する」をONにすると、既存の共通Vosk入力層を利用する。公開済みのモデルを読み込み、音声の解析は端末内で行う。音声外部送信はしない。タッチ操作を常に残す。

- 上下：「たかく／あげる」「ひくく／さげる」。かな・漢字の表記揺れを照合する。
- 「はんおん／半音」を付けた上下も同じ半音操作になる。
- 選択：「つぎ」「まえ」。確認：「きく」「オッケー／決定」「もどす」「とりけし」。
- 編集・待機中だけ受付。試聴中は認識を停止し、停止後250msの間を置いて再開する。
- マイクOFF・音声操作OFF・編集終了・画面非表示で入力を解放する。モデル準備中の中止も、遅れてマイクを開かないよう破棄する。

移動幅は使い勝手を比較するため半音に統一した試作。コードトーンを既定とする方式は未採用で、モードを増やす前に操作性を確認する。仮編集中は確認済みの音列から調号を推定して固定し、仮の音高に必要な臨時記号を表示する。点線枠で仮編集箇所も示す。

## 検証と限界

- 純粋ロジック：複数仮編集、確定前後Undo、取消のUndo、重なり拒否、全削除、終了時履歴破棄、音声語彙・受付外の結果・初期化取消・区間終了を検証。
- Chrome：実際の録音開始／解放と合成検出フレームを組み合わせ、3方式切替、仮編集・試聴・確定・再編集・Undo・終了・再開、JSON再読込を確認。320／390／844／1280pxで横のはみ出しなし。
- 音声は共通Voskアダプタと実AudioWorkletを通し、認識結果だけを模擬して語彙・試聴中遮断・マイクOFF・終了・モデル準備中取消を検証。実際の発話認識精度や子どもの操作性の合格を意味しない。
- 次の実機確認：Windows／Pixelで1回の取り込みを複数音直し、試聴→確定→再編集→Undo→終了を試す。音声ONでは「上げる／下げる」を言い、再生中に勝手な編集が入らないか確認する。追加の音高解析調整は今回行わない。
