保存曲は、曲名を横幅いっぱい、その下に「聴く・コピー・けす」を同じ幅で並べる。更新日時は独立した行へ置く。長い名前と狭い画面でもボタンを縮めて重ねない。保存件数が増えても閉じる・停止の位置を変えない。

`probe/saezuri/sheet-controls.js` がシートのヘッダ・スクロール部分・停止欄を共通化し、`screens.css` で配置する。閉じる・停止は再生中も操作可能。コード・進行の試聴は閉じる／Escapeでも止まる。全体設定は音量を調整して戻る用途を維持するため、閉じるだけでは再生を止めず、常設の停止を使う。

`scripts/test-saezuri-controls-browser.cjs` で保存曲6件・長い名前、上記6シート、制作3タブ・おためし・つなげる、320／390／844／1280pxを確認する。スクロール前後の右上位置、停止の左右中央、ボタン間隔、横はみ出し、再生中の閉じるとEscapeを検証する。保存・コード・音量・小節数・教程・音符長さの既存ブラウザ検証も併せて実行する。
