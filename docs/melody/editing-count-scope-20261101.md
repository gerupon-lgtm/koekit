# ドンカマを編集時のガイドに限定する

## 依頼と役割
利用者が「録音した曲を聴くだけでもドンカマが鳴る。ドンカマはガイドなので編集中に鳴らす想定」と指摘した。保存曲の再生へ編集用のON設定が共通適用される状態を再現した。

| 操作 | ドンカマ |
|---|---|
| 保存曲一覧で聴く（並べる前の録音・並べた曲） | 編集の設定がONでも鳴らさない |
| 曲全体の並び・選択した配置から後を聴く | 鳴らさない |
| 曲の並びの一か所、部品メニューで完成済み・つくりかけを聴く | 鳴らさない |
| フレーズ編集画面の聴く、コード進行・伴奏の候補を比較する試聴 | 「編集の試聴でドンカマを鳴らす」の設定に従う |
| 編集中の伴奏ループ、録音前のカウント、独立したドンカマの開始・停止 | 既存の設定と操作を維持する |
| 音の入れ方の練習 | 専用の準備カウントを維持する |

伴奏のドラムやハットは曲の一部であり、鑑賞用のドンカマと一緒に消さない。音符・伴奏・保存内容を変更しない。編集のON/OFF設定そのものも鑑賞へ移るたびに書き換えず、編集へ戻った際に維持する。

## 実装
共通プレーヤーへ、鑑賞用の呼び出しでは `listening:true` を渡す。曲全体の `sequence` と鑑賞では四分音符のガイドを無効にし、実際の音声予約と診断のcountSoundを同じ値にする。`standalone` は編集画面の追従表示から独立した試聴にも使うため、鑑賞の判定には流用しない。コード進行や伴奏比較の編集試聴は従来どおり設定を使える。

設定の説明を「編集の試聴でドンカマを鳴らす」へ具体化。保存曲の再生開始待ちも、カウント音があるように見える「カウント中」から「再生準備中」へ変更する。録音・ドンカマ音源・音量・強弱・刻みや予約の時計には変更を入れない。

回帰試験で、技術検証用の全体画面では伴奏パネルがないにもかかわらず、その未初期化の部品を参照してエラーになることを発見した。実在しない伴奏コントロールは未作成として扱い、同じ全体画面のネイティブ音声試験を再実行して通過を確認した。初回の失敗ログを消して成功扱いにせず、修正後の再実行を別フォルダーへ残す。

## 検証
`scripts/test-saezuri-editing-count-scope-browser.cjs`で、並べる前の保存録音・保存した曲・曲全体・選択配置以降・単独配置・完成済み部品・つくりかけとオッケー済みの各試聴について、実際のWeb Audio予約のcountEventsが0になることを確認する。編集画面のONと独立した編集比較ではcountEventsが正になり、OFFでは0になる。全ケースでメロディーと伴奏の音声予約は残り、編集のON/OFF、録音用カウントの設定、仮編集と保存曲の音・配置を保持する。

ネイティブのドンカマ音声試験で音量・強弱・小節頭・5拍の発音・停止後の発音漏れなしを確認。独立したドンカマ、保存一覧、設定役割、イメージ録音の回帰も確認した。ローカルの証拠は `.local-tools/editing-count-20261101/`。公開・最終Nodeの結果を追記する。
