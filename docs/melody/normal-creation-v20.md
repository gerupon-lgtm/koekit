# v20 通常作成の検証

2026-09-28。ハナウタ後の編集と同じ候補・確定・Undo・譜面・番号カード・試聴を使い、通常の音名入力を追加した。

## 操作

1. 上部「新しくつくる・音列を開く」から「じゆうにつくる」または「イメージからつくる」。空の4小節、C、120 BPMで開始する。
2. 高さ・長さを指定してド〜シ／やすみを押す。候補を「聴く」で確認し、「オッケー」で1音または休符を確定する。言い直しは同じ入力位置の候補を置き換える。
3. 声では「ド1」「うえミ2」「うえうえド4」「やすみ はんぱく／はんぶん」。次の発話へ「うえ」は持ち越さない。「スタート／きく」で候補を含む試聴、「オッケー」で確定。
4. 「入力する位置・小節数・キー」で小節・半拍位置、C／Am、4→8小節の空延長／コピー、8→4小節の短縮候補を指定。「3はくはん」は現在小節の3拍目後半。小節移動・拍頭移動の音声語は未追加。
5. 既存音の高さは共通の「たかく／ひくく」。音名・長さで置き換える場合はカードを選んで「選んだ音を置き換える」。短縮で空いた箇所は休符。重なり・末尾超過は確定不可で、後続音をずらさない。
6. 伴奏は4ジャンル、3リズム、C／Am各4進行から比較。ジャンル変更はリズム・進行をおすすめへ替え、メロディと現在のBPMを保持する。おすすめBPMは別ボタンで明示適用。伴奏変更も仮変更として試聴してから確定する。

通常入力は8分単位、C4〜C6の白鍵。既存のハナウタの16分単位・範囲外の音は変換しない。既存編集の半音移動も維持。表示は譜面／カード／両方から選べる。スマホでは1小節を横幅に合わせ、譜面の下へ音の入力と確定を集めた。

取り消し・Undo・終了は既存セッションを共有する。確定後のUndoで仮変更に戻った場合は、オッケーで戻した内容を確定してから次の音を入力する。通常作成の記録コピーと再読込は確定音列・キー・伴奏・BPMを復元し、Undoや未確定入力は復元しない。作品の自動保存機能ではない。

## 検証

- UTCの関連Node試験66件成功。候補置換、休符のカーソル、半拍不足、重なり、二重／古い確定、4／8小節、伴奏の範囲・旋律保持、読込、音声の受付区間を含む。
- Chrome：タッチ新規、音声結果から候補・確定、半拍休符、位置移動、エラー修正、8小節コピー／短縮取消、C／Am、伴奏の仮試聴、記録再読込、320／390／844／1280幅と文字200%を確認。
- 配信中の日本語Voskモデル＋Windowsのローカル合成音声で「ド 一」「上 ミ 二」「休み 半分」「三 拍 半」の認識と命令化を確認。実声での成功率とは区別する。音声の外部送信なし。
- 既存のハナウタ取り込み・編集・音声受付・音色、譜面／カードの再生追従・休符・タイ・停止復元のブラウザ回帰も成功。

実機で確認するのは、音を置く→聴く→確定の距離、声の音名＋長さ、伴奏の聞きやすさ。伴奏の具体的な配列・推奨BPM・合成音色は試聴用の初期値で、音楽的な採用確定ではない。
