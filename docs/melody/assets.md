# サエズリズム 名称・採用アセット

2026-09-27確定。要件の正典は[要件定義書](../requirements-melody.md)。ロゴと小鳥の基本姿勢をローカル試作へ組込み。本アプリへの組込み・公開は未実施。

## 正式名称

**サエズリズム**（サエズリ＋共通ズム）。旧仮称はミニメロディ。候補だったオトヅクリズム、ツナガリズム、オトノリズムは不採用。鳥のさえずりと、声・音をつないで曲を作る体験を表す。

## 採用ロゴ

- 採用SVG：[saezurhythm-wordmark.svg](references/saezurhythm-wordmark.svg)
- 配信用複製：[assets/brand/saezurhythm.svg](../../assets/brand/saezurhythm.svg)。採用SVGとSHA-256一致、色・形・共通ズムは変更なし。
- 確認用PNG：[saezurhythm-wordmark.png](references/saezurhythm-wordmark.png)

- サ・ズ・リはラベンダーブルー `#858fca`、エはあんず色 `#dfa277`、サエズリ側の濁点はライラック `#b1a3d6`。
- 末尾ズムは既存作品と同じ茶色の共通素材。末尾の濁点までライラックへ変えない。
- サエズリは既存イロドリズム等の丸い太線に合わせたSVGパス。システムフォントの置換ではない。共通ズムは `assets/brand/irodorhythm.svg` と同じ埋込み素材・配置を継承。
- v2〜v5等は比較過程の案。現行採用素材として使わない。デリバリズムに近い青緑系の案は撤回。

## 採用キャラクター：B

[小鳥A/B/C比較原画](references/bird-concepts-abc.png)の中央Bを採用。淡い水色の羽、クリーム色の顔、あんず色の胸とくちばし、音符風の冠羽を持つ小鳥。ロボットの部品や荷物は持たせない。

比較原画は組込み画像生成ツールで制作。制作指示は「温かい教育アプリの小鳥3案を同じ画風で比較。Bは淡い水色＋あんず色、音符風の冠羽。大きな基本姿勢と、首をかしげる／翼を広げる小さな姿勢」。デリバリズムの柔らかい造形・配色を参考にした。比較画像の原本はプロジェクト内へ複製済み。

基本姿勢の単体透過PNGを制作：[bird-neutral-v1.png](../../assets/saezuri/bird-neutral-v1.png)。1254×1254px、1,097,850 bytes。組込みimage_genで原画の中央Bを参照し、姿勢・目・冠羽・体の比率・色を保つ指示で生成。目視照合とPNG透過（四隅のalpha=0、中心alpha=253）を確認し、試作には縦横比を保つ144pxで配置した。生成原本は残し、プロジェクト内へ複製。PNGをプログラムで切り抜き・塗り替えしていない。

アニメーション用差分・画面ごとの状態割当・端末上の視認性は未確認。候補として示した「聴くときに首をかしげる／拍に合わせて小さく揺れる／完成時に翼を広げる」は、具体的な状態割当・動きの大きさを基本設計で詰める。基本姿勢の素材完成をアニメーション実装完了と扱わない。
