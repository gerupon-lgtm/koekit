# ハナウタ v16：音声で仮削除

2026-09-27。発案者がv15のPC音声操作を確認し、「けす」「9ばん けす」を追加要望。

- 「9ばん」→「けす」で選択した音を仮削除する。一息の「9ばん けす」でも同じ操作ができる。
- タッチの「けす」を上下・試聴と同じ操作欄へ移した。
- 削除した場所は休符になる。ほかの音の開始位置・長さは変えない。
- 削除後は次の音を選ぶ。末尾なら前の音、全削除なら選択なし。番号は発音順で振り直す。
- まとめてオッケーまでは仮の変更。「もどす」で音符と削除前の選択を復元できる。元の解析診断は保持する。
- 存在しない番号では選択も音列も変更しない。再生中・マイクOFF等では音声操作を受け付けない。

音声のノート追加は今回の対象外。通常の追加機能で位置・高さ・長さの指定、候補表示・試聴・確定を整えてから、同じ操作へ音声を接続して検証する順とする。

## 検証

- Node14件：語彙の完全一致・番号削除、休符の保持と隣接選択、Undo、仮編集セッション、音声受付区間。
- Chrome：16音の候補で2回に分けた「9ばん→けす」と一息の「九 番 消す」、範囲外指定、Undo、再生中の遅延した削除結果の無視を確認。320／390／844／1280pxで選択音が画面内に表示されることを確認。
- 録音・比較候補・仮編集・試聴・確定後Undo・終了／再開の既存ブラウザ回帰も成功。
- 日本語Vosk実モデル＋Windows合成音声：「けす」→`消す`→選択音の削除、「きゅうばんけす」→`九 番 消す`→9番の削除を確認。利用者の実声・スマホ環境の認識精度とは区別する。
