# 鍵盤の練習とタップ録音

2026-10-02。発案者が確認した画像の方向で実装。ローカル検証・公開先検証済み。[既存試作URL](https://koekit.sikumilab.com/probe/saezuri/)へ反映した。

制作画面に鍵盤を常設し、録音していない時は練習として鳴らす。練習は音符・候補・Undo・保存枠を変更しない。伴奏ループ中も演奏できる。上段には「伴奏ループ」「タップで録る」「ハナウタで録る」を同じ幅で置く。長調／短調の「あかるめ／くらめ」と4／8小節は従来どおり手前の1行に残す。

- 鍵盤はA3〜C5（MIDI57〜72）、白鍵10・黒鍵6の16鍵。「元」の中央C（MIDI60）の高さだけ控えめな薄紫。「下げ」では同じ高さのCが右端に移り、「上げ」では表示範囲外なので着色しない。押している鍵は淡い緑で表示する。
- 鍵盤の下に「↓ 下げ／元／↑ 上げ」。選択は保持し、録音中も±1オクターブ変更できる。既に押している音の高さと既存の音符は変えず、次の音から適用する。
- 押した時に発音し、離すまで保持する。Pointer Captureで鍵盤の外の指離しも処理する。pointercancel・capture喪失・blur・非表示・停止でも解除し、長押しの文字選択／メニュー／ページスクロールを抑える。音声準備中に指を離しても遅れて発音しない。
- 「タップで録る」で記録を開始する。停止中なら伴奏／カウントのループを起動して最初の先頭から、ループ中なら次の先頭から録る。待ち時間に弾いた音は練習とし、先頭まで押し続けた音は先頭から記録する。
- 4／8小節を繰り返し、停止を押すまで録音を続ける。開始位置・長さは16分音符単位、最短1tick。長押しは長い音になり、小節／ループの端を跨ぐ音も範囲内へ収める。入力していない位置の既存音は残し、重なった位置は新しい音を優先する。同じ開始位置の旧音は全体を置き換える。
- 録音中は音符を譜面に仮表示する。停止後に候補として既存編集へ渡し、音高・長さ・位置を編集、試聴して「オッケー」で確定する。録るだけで確定版を変更しない。「もどす」も既存の候補→確定方式で利用できる。音を記録せず止めた場合は変更しない。
- ハナウタとタップ録音は併用しない。ハナウタ中は鍵盤／高さボタンを隠し、録音案内を表示する。ハナウタは従来どおりマイクONが必要で、次の先頭から4／8小節の1フレーズを録り自動停止する。タップはマイクを要求しない。
- 伴奏ループ中の譜面は現在の小節・拍を追い、周回で先頭へ戻る。伴奏だけの再生で既存メロディーを発音中と表示しない。譜面内をスクロールし、ページ全体は動かさない。

伴奏設定・おすすめ、従来の「1音ずつ置く」は下の折りたたみに残す。おてほんでは1音入力を自動で開き、既存の案内を維持する。鍵盤以外のボタン間隔は8px以上、停止は画面下部中央。鍵盤はピアノとして白鍵を連続配置し、黒鍵を重ねる。

実装は `tap-recording.js`（独立した録音候補）、`live-keyboard-audio.js`（保持音の発音と解放）、`keyboard-controls.js`／`keyboard.css`（操作と配置）、既存 `app.js`／`capture-editor-view.js`（共通時計・停止・候補・譜面追従）。保存スキーマは維持し、patternのsourceに`tap`、gridStepに1を使う。録音中の仮表示は編集セッションを変更せず、停止後の候補から既存の保存へ接続する。録音途中の未停止テイクのクラッシュ復元は未実装。詳細なハナウタデータの確定時破棄は従来どおり相談待ち。
