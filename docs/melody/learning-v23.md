# v23 操作を覚える入口

合意: おてほんからつくる（チュートリアル）→おためしをアレンジ（プリセットのコピー編集）→じゆうにつくる。全入口を初めから選べる。既存の編集・候補確定・音声・試聴を共用する。

画面: 作り方に3段階の入口、おためし一覧は試聴と「これをアレンジ」。制作上部に短い手順と操作対象の強調。完了後におためしへ進める。登録後は「つなげるへ」「もうひとつつくる」。作業の切替はv22の破棄確認を維持。

既存他作品のbutton/seg/iconを引き継ぐ。背景#faf5ed、本文#493f36、案内#fff3d1、確定#dce9d5、補助#e7ddef。共通M PLUS Rounded 1c、左揃えの短い案内、スマホで1列。

4つの自作プリセットは独立複写して通常作成と同じデータにする。追加・削除・半音変更・伴奏選択が可能。プリセット自体は書き換えず、ギャラリー／永続保存とは分ける。ハナウタへの伴奏追加は今回の範囲外。

## 実装・検証

`learning-data.js`の4種自作メロディと手順判定、`learning.js`の選択画面と案内を追加。ド・ミを1拍ずつ候補→確定、1番を選択して高さを2半音上げる、試聴→確定で完了する。既存editorの実際の状態を見て案内を進め、操作を強制確定しない。案内だけ閉じる／戻って再開も可能。

おためしは「ひなたのさんぽ」「はずむステップ」「つきのこもりうた」「こえのキャッチボール」。元のデータは毎回複写し、通常作成と同じ音符追加／編集／伴奏を使える。試聴だけでは現在の音列とBPMを変更しない。編集へ移る時は既存の破棄確認を通す。登録後に「つなげるへ」「もうひとつつくる」を表示。

Node12件、Chromeの実操作チュートリアル完了・プリセット独立・BPM保持・伴奏・登録導線・破棄取消・4画面幅が成功。既存新画面の音声入力／録音退出／連結／文字200%とv22戻る・破棄の回帰も成功。音声・解析層は変更していない。永続ギャラリーは未実装で再読込時に作業は消える。
