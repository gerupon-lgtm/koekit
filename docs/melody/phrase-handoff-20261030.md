# 登録直後のフレーズ表示 — 2026-10-30

## 報告と再現

「フレーズにする」の直後に、そのまま「つなげるへ」を押すと選べるフレーズが表示されない、という報告。本人に直接の移動ボタンであることを確認した。

最初に調べた候補中の登録制限、保存待ちの有無だけでは、この直接経路の消失は再現しなかった。自由／イメージの通常保存と遅延保存、保存曲からの再登録（手入力／タップ／ハナウタ相当のsource未指定）、2回目の登録でも、登録データとボタンは存在した。

一方、既存フレーズが多いと、新規分が高さ180pxに制限した一覧の表示範囲外に入ることを再現した。既存9個・配置2個の320×568pxでは、新規10個目の上端が361px、一覧の下端が282px。新規分は有効なボタンとして存在するが、見えず、その位置に触れてもボタンに届かない。

従来のブラウザ試験はボタン数を確認した後、テスト操作が自動的にスクロールしてから押しており、この見落としを捕捉できなかった。新規試験は自動スクロール前の一覧内の座標と、実際にタッチが届くことを確認する。修正前にこの検査が失敗した。

## 修正

登録したフレーズへの一時参照を制作画面に残し、「つなげるへ」で移動した後、そのフレーズが見える位置へ一覧内だけをスクロールする。画面全体は先頭のまま、新規ボタンへフォーカスを移し、既存の緑系の色と内側の枠で強調する。

現在の一覧に同じフレーズのオブジェクトが存在する場合だけ処理し、別の曲へ移った後に同じIDがあっても対象にしない。追加の参照・強調は保存しない。フレーズの内容、登録済みの順番、候補→オッケー、取消、16配置上限、音声・録音の処理は維持する。
