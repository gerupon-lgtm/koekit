## 今回の画面

- 伴奏を選ぶ間は「音楽のタイプ・はやさ・ふんいき」「調・小節数」「別のパターン」「聴く・オッケー・もとにもどす」を使う。空の譜面と録音操作は閉じ、重複するジャンル・リズムと詳細設定は「こまかく えらぶ」へまとめる。
- オッケー後は「タップか ハナウタで 録ろう」と表示し、鍵盤・録音ボタン・音色・オクターブ操作を前面に置く。調と小節数は選択欄を閉じて、採用した内容の短い表示へ変える。2026-10-10の「調・小節数は選択欄を常設」は今回の指示に基づき更新する。変える時は「伴奏をえらび直す」で同じ選択欄へ戻れる。
- 選び直しを開いても、変更しなければ「録音にもどる」でそのまま戻れる。候補が残っている間は採用／取消を先に行う。戻るためだけに再生成や再確定を要求せず、曲・候補・Undoも変えない。
- 録音のために先に伴奏ループを押す必要はない。従来の録音ボタンから、伴奏の開始と録音待機をまとめて行う。既にループ中なら次の先頭から録る。鍵盤だけの練習や伴奏ループだけの練習も残す。ハナウタにはマイクONとブラウザーの許可が必要。
- 録音後は従来どおり試聴・オッケー・もどすを表示し、オッケーまでは録った音を候補として保持する。確定した音列・伴奏を先に書き換えない。
- タブ、ノート表示／入力表示、細かな編集は「音を直す・表示をかえる」にまとめる。表示は独立したまま、曲・候補・入力位置・Undoを変えない。「見る」「入力」の短い横並びラベルにし、同じカード／五線譜・カード／鍵盤を選べる。
- イメージの確定後・保存再開時は鍵盤から録音できる状態を出す。この自動表示では保存済みの入力表示の好みを書き換えず、自由制作に戻ると元の配置を使う。本人が表示を変更した時だけ従来どおり好みを保存する。
- 音のある譜面は表示し、小節全体が欠けないよう表示枠内へ縮める。伴奏・音符・選択の表示内容は同じ。停止は画面下中央、音色は鍵盤の上、操作群の8px以上の間隔を維持する。

タッチの録音開始を簡単にした配置変更で、声の意味は変えない。「スタート」でループ、「ろくおん／はなうた」はループ中の録音待機、録音中は停止という既存の受付を維持する。一般の制作、おてほん、進行候補4つ、手動コード、再生成でメロディーを保つ規則も維持する。

横断確認で「ロック」等がイメージ選択より詳細ジャンルとして先に解釈される重なりを再現した。イメージ制作では既存のイメージ語を優先し、自由制作／おてほんの伴奏ジャンルは従来どおりにする。声の「伴奏」は選び直し、「進行のおすすめ」は折りたたみ中でも既存の比較シートへ進める。選び直しを開いたまま声でループを始めた場合も、採用済みの内容で録音画面へ移る。語彙の追加・常時認識化・音声送信はしない。
