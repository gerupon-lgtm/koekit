# 音符を16分音符ずつ動かす（2026-10-18）

## 方針と操作

通常画面は音高・長さと入力先の選択が中心で、既にある音を少し前後へずらす専用操作がなかった。詳しい編集の開始位置入力は残し、子どもにも押せる2ボタンを「音を直す」に追加する。

- カードまたは五線譜の音を選び、「← 16分まえ」「16分あと →」で1回につき16分音符1つ分だけ動かす。音高・長さ・同じ音を示すID、ほかの音、伴奏は保つ。小節をまたぐ移動も同じ操作。
- ボタンの上に現在位置を「2小節目・1拍目＋16分1つ」のように表示する。隣の音を選ぶ「まえ／つぎ」と別の操作であることを示す。
- 利用者の回答により、別の音と重なる移動は拒否する。押し出し・長さの自動変更・上書きはしない。曲の先頭より前、音の末尾が曲の終わりを越える移動も止める。
- 仮の変更を試聴し、オッケーで確定。「もどす」は1クリック分ずつ戻す。移動は入力カーソルを勝手に進めない。再生・録音中や1音入力の候補が未確定の間は操作しない。
- ハナウタ・タップ録音・手入力で共用する。録音後の候補、確定後、保存再開後の音も編集できる。イメージ制作では「音を直す・表示をかえる」を開いて「音を直す」へ進む。
- 声は「音をまえへ／音をうしろへ」。単独の「まえ／つぎ」は従来どおり音の選択。録音中は従来の停止語だけを受け付け、移動語は受け付けない。

`capture-editor.js` の編集候補を既存のセッション・確定・取消・Undoへ通す。8分単位の手入力／読み込みも16分だけ移動できるよう、その候補の最小単位を16分へ細かくする。他の音の時刻は丸め直さず、Undoで元の最小単位にも戻る。保存の形式は変えない。手入力の「記録をコピー」も、この16分の位置を読み戻せるよう受け付け範囲を更新する。従来の手入力・タップ・録音記録は引き続き読める。

位置を手で直す操作も「手修正」に含むため、録音の自動的な頭詰めは従来どおり修正前だけ使える。音源・音の予約・用途別遅延・ループの先頭予約・録音の取り込み処理は変えない。
