# イメージ選択・ループ録音の音声操作

2026-10-02、発案者の検証用の追加依頼を実装。マイクONと「声で操作」が必要。タッチ操作と端末内Voskを維持する。

| 発話 | 動作・受付区間 |
|---|---|
| スタート | 制作の停止中、確定済みの伴奏をループ開始。未確定候補がある間は開始しない |
| ストップ | 伴奏ループ、録音待機、録音を停止。停止ボタンと同じ処理 |
| はなうた | 伴奏ループ中にハナウタを予約。次の先頭から4／8小節を録り、自動停止 |
| ろくおん | 伴奏ループ中にタップ録音を予約。次の先頭から停止まで周回 |
| どうよう／ポップ／ロック／バラード | イメージ制作の停止中、音楽のタイプを選ぶ |
| ゆっくり／ふつう／はやい | イメージ制作の停止中、はやさを選ぶ |
| あかるい／やさしい／かっこいい／かなしい | イメージ制作の停止中、ふんいきを選ぶ |
| 別のパターン | イメージ制作の停止中、伴奏だけの別案を候補にする |
| きく／オッケー／もどす | 従来の試聴／確定／Undo |

停止中の「はなうた」「ろくおん」は動作しない。声の録音予約はループ中だけ。タッチの録音ボタンは従来どおり停止中からも開始できる。タップとハナウタは排他。予約取消では確定した曲を変えず、タップ録音停止後は既存の編集候補へ接続する。

イメージ選択は画面のプルダウンと同じ生成処理を使い、連続変更は1つのUndoで戻せる。手動コード・音色・音符・調・BPM・小節数は保持。音符や構造を編集中は受け付けず、先にオッケー／取消で決める。自由制作ではイメージ語彙を登録しない。

## 受付の制限と重複

- ループ中は「はなうた」「ろくおん」と停止だけ。待機中・録音中は停止だけ。イメージ選択・再生成・音符編集・確定を受け付けない。
- 通常の試聴中、準備・解析・保存中、別画面・設定シート、非表示タブ、マイクOFF・音声操作OFFでは受付を休止する。退出・マイクOFF・非表示等で認識用マイクを解放する。
- 新しいイメージ語・録音語・停止語は、既存の音名／長さ／移動／編集語と完全一致で重複しない。「スタート」だけは旧音符入力の試聴別名を、ご指定の伴奏ループ開始へ置き換える。「きく」は試聴のまま。「つぎ」は音符移動のままで、再生成には使わない。
- 文章の一部を拾う判定はしない。認識結果全体との一致のみ。「タイプ ロック」「速さ ゆっくり」「雰囲気 やさしい」も使える。

録音・伴奏中の上記の限定受付は今回の発案者指示による追加。従来の「音を出す区間と編集の発話受付を分離する」方針に対し、検証用の録音予約・停止だけを例外とする。他作品の受付や共通音声コードは変更しない。

## 実装と検証

`probe/saezuri/creation-voice.js` の固定プロファイルを `app.js` で状態ごとに選ぶ。録音ボタン・停止ボタン・イメージ選択の既存処理を呼び出す。`edit-voice.js` は準備済みの認識入力を使い回して語彙だけを変更できる。切替前・休止後の遅れた結果は無効。ハナウタ録音中の80msごとの状態更新でも受付開始を先送りしない。

- 新規Node検証：イメージ全別名の重複、既存全編集／音名語彙の互換、「スタート」の変更、区間ごとの限定受付、旧認識結果の排除、入力再利用。全30ファイル213件成功（最大5ファイルずつ直列）。
- 新規Chrome検証：実際の画面と音声コントローラーを、Vosk認識結果だけの模擬入力で動かす。11選択肢、候補差替え・Undo・確定、ループ開始、両方式の次の先頭待ち、待機取消、ハナウタ録音中の停止、鍵盤を押したままのタップ録音停止、旧結果／通常試聴／設定／マイクOFF／非表示の制限を確認。
- 配布モデルの抽出済み `words.txt`（2026-09-29の語彙確認）で追加文法56句の全トークン存在を確認。読みに対応する辞書表記「鼻歌」「録音」を文法へ登録し、ひらがなは解析側の別名に残す。

実声の認識精度・伴奏やハナウタによる誤認識・スマホ実機の遅延はこれからの検証対象。語彙の完全一致で重複がないことと、実際の音から誤認識されないことは別。モデルの実声精度を模擬結果や辞書の存在確認だけで合格とはしない。
