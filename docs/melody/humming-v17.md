# ハナウタ v17：確定語・試聴音色・全体移調

2026-09-27。発案者の要望により、次を追加・修正した。

- 音声の「オッケー／オーケー」：確定処理は実装済みだったが、Voskへ渡す語彙がひらがなだけだった。配布モデルの辞書に存在するカタカナ表記を追加。編集を開き、マイクON・「声でも操作する」ON・試聴停止中に使う。
- 試聴のドンカマ：リムショット風（初期値）、スティック風、タンバリン風、従来のシェーカーを選べる。新3音色は周期的な発振音を使わない短いノイズの合成音。小節頭を強くし、共通の3段階音量を適用する。録音・準備カウントのシェーカーと実測補正は維持。
- メロディー音色にシンセリードを追加。上限周波数を制限した倍音合成と、長音で減衰しすぎない音量カーブを使う。試作用の合成音であり、本アプリの音源採用は未確定。
- 編集中の音列全体を±12半音／±1半音トランスポーズできる。「全体を1オクターブ上げる」→「流れを聴く」→「まとめてオッケー」。確定済みなら「この音列を編集する」から開く。
- 移調は実際のMIDI音高を変える。「1オクターブ上に表示」と独立。開始位置・長さ・休符・音程間隔を保持し、一操作としてUndoできる。確定前は仮、元の解析診断は変更しない。いずれかの音がMIDI 0〜127を超える移調は全体を拒否し、個別の切り詰めはしない。

## 検証

- Node27件：移調の原子性・確定前の保持・Undo・範囲外拒否、既存編集、削除・番号指定、音声区間とモデル辞書に対応した確定語。
- 日本語Vosk実モデル＋Windows合成音声：「オッケー」→`オッケー`→確定コマンドを確認。利用者の実声での認識精度とは区別する。
- Chrome OfflineAudioContext：全4カウント音色の3音量・アクセント・発音前後の無音・予約取消、シンセリードの持続音を確認。実スピーカーでの聞こえ方は次の実機確認対象。
- Chrome：全体移調の仮試聴で実音高が+12、シンセリード／カウント音色の反映、Undo、確定後Undo、再生中の編集禁止、音声確定、既存の番号操作と320／390／844／1280px表示を検証する。
