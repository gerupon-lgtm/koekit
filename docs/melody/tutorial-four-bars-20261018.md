# おてほんを4小節まで育てる — 2026-10-18合意

状態: 発案者が完成形・段階別操作・配置案14を承認。この合意に沿って本アプリへ実装し、PC Chrome／Nodeで確認。結果は[実装・確認記録](tutorial-implementation-20261018.md)へまとめる。会話中の試聴案と本アプリの確認結果は区別する。

## 目的と制約

完成形を最初に聴き、同じ曲を2音→1小節→2小節→4小節→伴奏付きへ育てる。既存の制作、候補→オッケー、Undo、譜面、端末内音声を使う。音符や伴奏を案内側で自動確定しない。タッチだけでも完了できる。

通常制作、保存曲、鍵盤、ハナウタ、ループ録音、配置編集、他作品を維持する。案内を閉じても練習を終えず、現在の操作画面を維持する。各段階は「できた！」の後に「もう一度 聴く／つぎへ」を自分で選ぶ。おてほんの途中を通常の保存枠へ自動登録しない。

2026-10-18訂正：カウントは「4分音符を4つだけ」。以前の「1拍4発＝16発」は実装側の解釈違いとして訂正する。待つ長さは1小節のまま。

## 完成形（112 BPM、C、4/4）

時刻は1拍=4 tick、1小節=16 tick。C4=60。重複した同音は別の発音、タイだけ一続きの発音とする。

|小節|音と長さ|
|---|---|
|1|D4 1拍、E4 1拍、G4 半拍、E4 1拍半|
|2|F4 1拍、E4 1拍、D4 2拍|
|3|G4 1拍、半拍休符、G4 半拍、A4 半拍、G4 1拍、E4 半拍（次小節へ）|
|4|前のE4の続き半拍、D4 1拍、C4 半拍、C4 2拍|

旋律の発音は15音。3小節目4拍目裏のEは `startTick=46,durationTick=4` の1音。4小節目のD/C/Cはそれぞれ `[50,4,62] / [54,2,60] / [56,8,60]`。Eを小節頭で鳴らし直さない。

伴奏はC→F→G→C。各小節のコードは `8,8,r8,8,8,8,r8,8`（tick 0,2,6,8,10,14）、ベースは休符なしの8分刻み。合意済み試聴案と同じFMエレピ、シンセベース、電子打楽器を使う。ベースgain=.12、コードは頭=.06/他=.045、キック頭=.09/3拍目=.055、スネア=.05、裏ハット=.02/頭ハット=.035。伴奏velocity=55。コード位置は各小節の1拍目の上。

## 段階ごとのシナリオ

0. 導入: 伴奏付きの完成形を聴き、「つくってみよう」。制作中も見本を聴き直せる。
1. 最初の2音: ド1拍→オッケー、ミ1拍→オッケー、聴く、最初の音を選ぶ、たかく2回でレ、聴いてオッケー。完成はレ・ミ。
2. 1小節: 1小節のおてほんを聴く。半拍を選びソ→オッケー、1拍半を選びミ→オッケー。1小節を聴いて完了。この段階は長さを選んでから置く。
3. 2小節: 前半2小節のおてほんを聴く。ファ・ミ・レを各1拍で置く。最後のレを選び、2拍へ伸ばす候補を聴き、オッケー。
4. 3小節: 後半のおてほんを聴く。ソ1拍、休み半拍、ソ半拍、ラ半拍、ソ1拍、ミ半拍を順に置く。休符も候補→オッケー。
5. 小節をまたぐ: 最後のミを選び、半拍から1拍に伸ばす。自動で4小節目へ半拍続く候補を聴いてオッケー。前後2音の選択・結合は要求しない。次の入力位置は伸ばしたミの終わりへ進める。
6. 4小節: レ1拍、ド半拍、ド2拍を続けて置き、全体を聴く。
7. 伴奏: 「おてほんの伴奏をつける」で候補を作る→聴く→オッケーで完成。音声も「ばんそうをつける→きく→オッケー」。完成後は既存のアレンジ入口や通常の編集へつなぐ。

誤った入力をした場合は、現在の音を保ち、どこを直すか案内する。「もどす」や候補取消が使える。段階の完成後も自動では次へ進めない。未確定の候補・停止しただけのカウントを完成と数えない。

## 音声

既存の「ドいち」「ソはんぱく」「さいご」「たかく」「きく」「オッケー」「もどす」を再利用する。音名の後の `いっぱくはん / ふてんいち / ふてんいっぱく` は同じ1.5拍。例「ミ ふてんいち」。選択中の音への「いっぱく／にはく」等の長さ指定は、候補として変更し、オッケーで確定する。

新語の文字列照合・認識辞書への登録と、Voskモデルの語彙・実声認識の確認を分ける。実機の聞き取りを模擬コマンド検証で代用したと報告しない。声で進む／聴く／確定する経路も検証し、試聴画面が音声操作を閉じ込めないようにする。

## 試聴と表示

おてほん・部分・制作途中・伴奏付き、毎回の試聴前に1小節のカウントを入れる。4分音符を4つ（1拍1発、計4発）。112 BPMに同期し、カウント後の小節頭から曲を始める。カウント中の停止・画面終了・背景移動では予約された音も取り消す。

カード／五線譜を前面の切替で選べる。試聴中は入力用操作をたたむ専用表示にし、4小節、右上のとじる、中央の停止を収める。再生中の表示切替は音を再開・中断しない。コードは小節頭に表示する。表示案14を基準に既存の色・丸み・フォントを使う。制作側でも同じ選択を使い、入力は操作中の小節を読みやすく表示する。
