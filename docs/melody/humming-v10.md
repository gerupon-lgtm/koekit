# ハナウタ試作v10 — 準備待ち1秒とドンカマ音量3段階

2026-09-27。発案者はカウント欠落について「USBスピーカー側のエンコード・デコードが間に合わなかったことが原因のよう」と説明。これは発案者の機器についての所見であり、診断JSONだけで原因を確定したものではない。心の準備のためにv9の半分の待機を残したいとの依頼を受け、マイク準備後の待機を2秒→1秒へ変更した。

カウント／録音の共通基準時刻と残り秒表示は維持。診断は`ML-T01-v10`、`capture.timing.startLeadSeconds=1`。実測補正・カウントの拍配置・音程解析は変更しない。既存の通常操作ブラウザ試験で待機中のマイクOFF取消と録音・候補確定を確認する。

## ドンカマ音量

追加依頼「PCのスピーカーだと聞こえづらい、3段階で調整したい」に対応。「1. 音色と再生位置」に準備・録音・試聴共通のドンカマ音量を追加。小0.5倍／中1倍（既存・初期値）／大2倍の再生ゲインで、小節頭の強弱は保つ。旋律の音量は変えない。演奏・録音中は変更を無効化し、次の開始に適用する。設定は当該ページ内で共有、再読込すると中へ戻る。

`captureOptions.countVolume`と`playback.countVolume`で設定値を記録。既知波形と実測の正規化相関は維持し、参照波形自体は変更しない。出力ノードにGainNodeを追加し、停止／終了時に両方を切断する。小節頭の最大出力は小0.09／中0.18／大0.36、通常拍はその半分。知覚音量が倍率と同じとは限らない。

実波形の3段階の比率、無音区間のカウント、アクセント、OFF／停止／予約取消と、UIから録音・再生の設定記録へ値が渡ることを既存ブラウザ試験で検証する。実スピーカーでの聞こえ方・回り込みは実機で比較する。
