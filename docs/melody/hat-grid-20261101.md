# ハットの刻み・アクセントとコードの空白

## 合意した操作
2026-11-01、ハットの8分・16分刻みを追加し、刻みとアクセントを2段の選択欄に分ける依頼を受けた。重複した「二分音符表」は「二分音符裏」の意味として、次の6種類を利用者が承認した。

| 刻み | 1小節の発音位置（1拍=4tick） |
|---|---|
| 二分音符・表 | 1・3拍（0,8） |
| 二分音符・裏 | 2・4拍（4,12） |
| 四分音符・表 | 毎拍（0,4,8,12） |
| 四分音符・裏 | 毎拍の半拍後（2,6,10,14） |
| 八分音符 | 1拍に2回（0,2,...14） |
| 十六分音符 | 1拍に4回（0,1,...15） |

「伴奏の設定」の上段は「刻み（打楽器）」、下段は「アクセント」。上段はおまかせ・打楽器なし・6種類のハット。下段は均等、1／2／3／4拍目、1・3拍目、2・4拍目を強くする候補から、その刻みで使えるものを表示する。二分表は均等／1拍／3拍、二分裏は均等／2拍／4拍。おまかせ・なしではアクセントを無効にして説明を表示する。

八分・十六分は指定した拍の最初の音だけを強くし、四分裏はその拍の裏の音を強くする方針を利用者が承認。細かい裏の音を個別指定する編集は今回の範囲に含めない。強い音.06／弱い音.008、均等.02は前回の合意を維持する。コード変更でハットの拍をずらさず、ハット以外の打楽器を混ぜない。

刻みを変更して既存のアクセント位置が使えなくなる場合は均等へ戻し、未確定の間にその理由を表示する。Undoや確定の後に古い説明を出さない。候補→試聴→オッケー、Undo、閉じる、保存再開は共用する。新しい画面は追加せず、設定の下部「とじる」を維持する。

## 保存と実装

イメージの「別のパターン」とJSON再読込でも両項目を保ち、「手直しを外しておまかせ」で両方を解除する。音色のドラムを「なし」にした場合はアクセントも解除する。明示したハット選択ではドラム音色を有効に戻し、おまかせでは明示ミュートを解除しない。既存の曲の並び・草稿・コピー・元編集へ同じ保存と演奏を利用する。

## コードの空白（追加合意）
2026-11-01、小節内のコード指定と同じ四分音符単位で「空白」を指定する要求を受けた。利用者は、空白区間ではコードとベースを休ませ、メロディーと打楽器を続ける方針を承認した。「打楽器なし」と組み合わせられる。

コード編集のタブの横に「空白にする」を置く。選ぶだけでは曲を変えず、「つかう」で候補へ入れ、最後の「オッケー」で決める。指定した拍から、同じ小節の次のコード指定（なければ小節末）まで空白になる。1拍だけ空ける場合は次の拍でコードを指定する。「この指定を外す」で前のコードへ戻せる。空白はコードのお気に入り枠には登録しない。

保存では `{rest:true,startTick,durationTick,manual:true}` を通常のコード区間と同じ配列へ記録する。空白同士は統合し、再生成・長さ変更・コピー・草稿と確定済みの試聴でも保持する。和音・ベースの音を区間境界で切り、打楽器の位置と強弱を変えない。全小節を空白にし、メロディー・打楽器もない部品は「1小節の空白」のように説明し、曲に並べた長さだけ時計を進める。空白で終わる曲にエンディングを追加しても不正な音を生成しない。
