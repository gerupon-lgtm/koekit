# プルダウンの読みやすさ（2026-10-28）

## 変更

通常のサエズリズムで使うプルダウン全体が対象。コードの「すべて」だけでなく、イメージ、調、小節数、音色、表示切替、音量、設定の詳細、チュートリアル試聴にも適用する。

- 13／14／16pxに分かれていた文字を16px・700の太字へ統一。既存の丸ゴシックと濃い茶色を使い、背景は白に近いクリーム色、枠と矢印も同じ調子に揃える。
- iPhone系の選択文字にも色を明示。無効な項目も文字を薄い透明表示にせず、灰色の背景と読める文字色で区別する。
- `<select>` と選択処理はそのまま使い、選択肢の表示は端末の標準操作を維持する。矢印の領域と文字が重ならないように共通の内側余白を確保する。
- 音色、長いイメージ語「かっこいい」、リズム「音をばらして弾く」、調の欄へ横幅を配分。画面の下へ積み足さず、操作の高さ44px以上を保つ。
- 最小画面320×568では、既存チュートリアルの確定ボタンと固定停止欄の間隔不足を変更前CSSでも再現した。横画面を含む高さ600px以下に限って案内の余白と行間を詰め、文字・ボタン・譜面のサイズを保つ。

変更はCSSのみ。音源・発音タイミング・単独コードの増幅・録音・声・確定・保存の処理は変更しない。
