## 2. 全体像と導入

曲は、部品・並び順・設定・つくりかけをまとめて持つプロジェクトとして扱う。まず曲全体が見え、その中の部品をつくる・直す・並べることで仕上げる。

導入では、完成したサンプルの全体と部品の関係を先に見せる。「部品をつくる方法」だけでなく、「部品をつないで曲になること」を伝える。基本の一往復は次のとおり。

> 曲全体を見る → 部品をつくる／直す → 曲全体へ戻る → 部品を並べる → 全体を聴く

検討の共通の土台は、異なる4小節の部品A・B・Cを持ち、A–B–A–Cと並べた固定サンプル。部品は3種類、使う場所は4か所、全16小節で、同じAを繰り返し使っていることが見える。各部品と曲全体の再生対象を区別して表示する。

サンプルを使って操作を確認したことを、新規曲は必ずサンプルのコピーから始めるという決定に読み替えない。【2026-10-31追加承認】トップに「サンプルでためす」を置く。試用中は保存枠を使わず、「自分の曲にする」で保存する。サンプルは毎回原本から開始し、新規曲は空の全体から始める。

## 3. 部品をつくる・戻る・直す

### 新しい部品

1. 曲全体の部品一覧から「＋つくる」を押す。
2. その曲の中に独立した新しい部品を用意し、その編集へ入る。
3. 作業はその部品へ残す。途中で全体へ戻っても「つくりかけ」として保持し、同じ部品から再開する。
4. 音の候補はオッケーで決める。戻っただけでは未確定の音を確定しない。
5. 作った部品は一覧に残るが、曲の並びには自動で入らない。使う場所は後で決める。

**作成後に別の「フレーズにする／登録」を要求しない。** 無音・編集途中の部品も、それを作り始めた作業として保護する。戻るたびに新しい部品を重複作成しない。既存部品や並びを、新部品の作成で上書きしない。

### コピーして直す

並べる前でも、部品一覧のAからコピーして修正版A2をつくれる。元のAを残し、A2は同じ曲の別部品にする。この操作だけでは既存の並びを変えない。

並べたA–B–Aの後ろのAだけを直す場合は、その配置を選び、元のAを残して修正版A2を作る。確定後はA–B–A2となり、先頭のAやほかの配置は変えない。候補の試聴・取消・Undoと、作りかけの保護を維持する。

確定済み部品の全配置を一括で上書きする編集は、今回のコピー編集の合意から自動的に追加しない。必要な場合は影響範囲を示して別途確認する。

## 4. 並びに入れる二つの入口

| 出発点 | 操作 | 結果 |
|---|---|---|
| 部品一覧 | 部品を選ぶ → 並びに入れる → 入れる場所を選ぶ | 選んだ場所への追加候補を表示 |
| 曲全体の並び | 先頭またはカード付近の「＋」 → そこに入れる部品を選ぶ | 場所を先に決め、部品を選んだ追加候補を表示 |

両方を用意する。部品の編集画面を経由しないと配置できる場所を選べない導線にはしない。先頭・途中・最後に入れられ、空の並びからも始められる。同じ部品を複数回使える。

候補を選び直すと、追加候補のカード1枚を差し替える。選ぶたびにカードを確定追加しない。候補の曲全体を聴いてからオッケーで決め、取消なら元の並びへ戻す。作った部品は取り消さない。

配置は部品単位。1拍だけずらす・部品同士を重ねる自由配置まで合意した意味ではない。既存の4／8小節、最大16配置、配置部分最大128小節、任意エンディングを含む最大132小節を維持する。サンプルの4小節のみの簡略編集を、本番の4／8小節や鍵盤・ハナウタ機能の縮小に使わない。

## 5. 長押しで移動・並びから外す

### 移動

1. 並びのカードを長押しし、「外す」「移動」のメニューを出す。
2. 「移動」を選ぶ。移動対象が分かる見た目にする。
3. カードをもう一度押さえ、指で移動先へ運ぶ。カードは指について動き、置ける場所には隙間または線を表示する。
4. 指を離すと、その位置の移動候補を表示する。
5. 試聴してオッケーで決める。取消なら元の並びへ戻す。

カードの個数・部品の内容・曲の長さは移動で変えない。同じAが複数あっても、選んだ配置だけを動かす。移動しない短い接触、元の位置へのドロップ、範囲外で離す、指操作の中断、Escapeで、誤って確定しない。

通常の縦スクロールとカード移動を区別する。「移動」を選んだ後の操作だけでカードを動かす。長押し待ち中に指が動いたら通常のスクロールとして扱い、後からメニューを誤表示しない。移動中の画面端では必要な範囲の補助スクロールを行い、指を離した後には停止する。

【想定・調整値】サンプルの長押しは約0.5秒。押し始めの移動許容距離、線の太さ、画面端の判定と速度は実機の操作感で調整する。サンプルの数値を本番の確定値とみなさない。

### 外す

長押しメニューの「外す」で、その配置を外した候補を表示する。試聴・オッケー／取消を経て決める。**曲の並びから外す操作で、部品そのものを削除しない。** 同じ部品のほかの配置、部品一覧、つくりかけは残し、後で再配置できる。

最後のカードを外して空の並びにする場合も、曲と部品を削除しない。空なら全体再生を無効にし、「＋」から並べ直せる。

長押し・指移動を主導線として採用する。サンプルに残っている移動先の文章選択・通常タップ後のボタンを、そのまま最終の主導線と解釈しない。PC・キーボード等の代替操作は既存のタッチ操作維持と両立させ、配置ごとの対象が分かる形に整理する。

## 6. 保存と互換性

- 曲単位の端末内保存、最大10曲、保存済みの曲を勝手に削除しない規則を維持する。
- 部品の確定内容・部品ごとのつくりかけ・確定した並び・並びの候補・編集対象の配置を混同しない。保存成功とオッケーによる内容確定を別に扱う。
- 本番では、部品を切り替えても編集対象がすり替わらず、複数の部品の途中作業を失わないようにする。
- 既存の直列保存、保存世代・別タブ競合の検出、保存失敗時の作業保持と明示再試行、トップへ戻る際の保存待ちを維持する。
- 既存曲の登録済み部品・制作中の未登録内容・配置修正のつくりかけを、新しい部品単位の作業へ移す。移行による自動確定・削除・音符／伴奏／テンポの変更を行わない。
- 【実装時設計】保存形式と旧checkpointの移行方法、未配置・無音の新部品を含む復元、Undoの保存世代との整合を具体化して検証する。新形式を既に実装したとは扱わない。

## 7. 縦スクロールと表示の重点見直し

発案者が提示したスマホ画像では、上部の画面切替・設定・説明・譜面が積み重なり、主操作が下へ押し出されている。「音を置く」は長さや音の入力操作が画面下に続き、「伴奏」も設定と確定・コード操作が縦に分散している。追加した曲内切替欄も高さを増やす要因として確認する。

機能の存続・横はみ出しなし・ボタンが押せることだけで、操作性を合格にしない。旧版に比べて主操作までの移動が増えていないかを比較する。

- よく使う操作を作業対象の近く、画面の上の方へまとめる。新しい操作を足すだけで縦に積み増さない。
- 説明・補助設定は必要時に開く形へ整理する。文字や譜面の読みやすさ、44px操作・8px間隔、停止への到達性を保つ。
- 「音を置く・音を直す・伴奏」、手入力・鍵盤・ハナウタ・イメージ制作、4／8小節を対象にする。曲全体・部品一覧・長押しメニュー・候補の試聴と戻りも含める。
- 同じスマホの実際に使える表示高、同じデータと操作で旧版／新版を比較する。上部の常設領域の高さ、主操作が初期表示で見えるか、操作一巡のスクロール量、固定停止欄による遮蔽、戻った位置を記録する。
- 320／390px、横向き、文字拡大、PC、実機のブラウザ上下バーと安全領域を含める。幅の検査だけで縦の確認を代用しない。難しい対象を無断で検証範囲から除外しない。

### 「画面が勝手にスクロールする」の扱い

確認用の表示枠には内容の高さを自動調整する処理があり、外側の表示位置に影響する可能性がある。実際、検証用ラッパーでは画面切替の高さ変化が、自動操作の座標に影響するケースを確認した。ただし、これを本人が見た全スクロールの原因と断定しない。

一方、サンプルの`dragTick()`は、カードを移動中に端へ運ぶと`window.scrollBy()`を呼ぶ。これは意図した補助動作で、表示枠だけの制約ではない。サンプル本文には通常の確定・取消で上端／下端へ飛ばす`scrollTo()`や`scrollIntoView()`は確認されなかったが、表示枠の伸縮・フォーカス・ブラウザ側の位置調整との合成は実機で切り分ける。

**本番の受入方針**：通常の切替・確定・取消・メニュー開閉で意図せず位置を見失わない。必要なフォーカス移動や録音用表示への遷移も確認対象にする。ドラッグ中の端の補助スクロールとは別に評価する。高さが縮む場合のブラウザの位置補正も含め、主操作と現在の対象が追えることを確認する。「本番では自動的に解消する」として検証を省略しない。

## 12. 本番接続で具体化した扱い

- 配置済み部品に未確定の作業が残る場合も「つづきをつくる」で再開できる。既存の並びを変えないため、作業中の候補ごと独立した修正版へコピーして編集する。元の確定内容・草稿は残す。
- ブラウザーの戻る等で古い編集画面へ入っても、配置済み部品の確定内容を変えると独立した新部品へ分け、全配置を書き換えない。
- 通常の部品切替と配置修正の全体往復では、制作中のUndoを保持。再読込のUndoは既存方針どおり初期化する。
- 配置修正を保留中は、その修正の再開を表示し、別の配置変更・エンディング候補・並びのUndoを止める。修正の内容確定／取消後に並びを変えられる。
- 従来のおてほんは保存枠なしで操作を練習できる。完了後の「このパーツで曲をつくる」で自分の曲へ移す。

保存形式は[部品ごとのデータと移行](project-data-model-20261031.md)、実画面と検証結果は[実装記録](project-workflow-implementation-20261031.md)を参照。
