# イメージ制作の実装・試聴案

2026-10-02。[実装依頼](image-mode-implementation-prompt.md)の合意内容を既存の制作画面へ接続した。編曲データは試聴用の提案であり、音楽的な品質・BPM案の本採用は未決。

## 操作

検証用に音声選択も接続した。マイクONと「声で操作」で11選択肢と「別のパターン」を発話できる。「スタート」は伴奏ループ、「ストップ」は停止。ループ中の「はなうた」「ろくおん」で次の先頭から録音へ進む。[受付区間・重複・検証](creation-voice.md)。

1. 「つくる」→「イメージからつくる」。音楽のタイプ・はやさ・ふんいきが前面に出る。最初の伴奏も候補。
2. 言葉を変えるか「別のパターン」で伴奏の別案を作る。「聴く」でメロディーと合わせて確認し、「オッケー」で採用。「もとにもどす」で採用前へ戻る。
3. 採用後は、常設鍵盤で練習、伴奏ループ、タップ録音、ハナウタ、従来の1音入力へ進む。同じ編集・保存処理を使う。
4. 個別コード・音色等は「伴奏の設定・進行のおすすめ」から開く。手動変更は再生成でも残る。外したい場合だけ「手直しを外して おまかせ」を使う。これも候補で、採用前に戻せる。

選択肢は合意の4タイプ×3はやさ×4ふんいき。各組み合わせに8案を用意し、順に切り替える。無秩序な音符の乱数生成は使わない。自由制作の基本4進行と編集画面は維持する。

## 編曲の提案

| 言葉 | 試聴用の方向 |
|---|---|
| どうよう | 木琴風の和音と規則的な低音、基本的な打楽器 |
| ポップ | ピアノ風の裏拍、根音・5度・オクターブの低音、電子打楽器 |
| ロック | シンセの和音、拍ごとの低音、キックとスネア |
| バラード | ピアノ風の分散和音、ゆったりした低音、控えめな打楽器 |
| あかるい | 基本和声から始める、軽めの強さ |
| やさしい | 分散・交互の弾き方、控えめな強さ |
| かっこいい | 強めのアクセント、低音と打楽器の動き |
| かなしい | 相対短調系の進行から始める、柔らかな分散和音 |

8案は進行、和音の転回／上向き・下向き・交互の弾き方、低音の根音・5度・オクターブ、打楽器の位置を組み合わせる。各調の和声と小節範囲に収まるレシピを保存する。「かなしい」を選んでも現在の調やメロディーを自動変換しない。

**BPMは再生成で維持する。** 今回の「はやさ」は伴奏の音数・刻み方にも反映する。BPMを合わせて試す時は、伴奏設定の「BPM案にする」を明示的に押す。提案値はゆっくり80／ふつう120／はやい144。値と、この刻み方・BPM操作の関係は試聴・操作相談の対象。調と小節数は、従来の前面配置の指示を保ち、イメージの4種類のふんいきとは区別して「調」を表示する。

まず「どうよう×ふつう×あかるい」「ポップ×ふつう×やさしい」「ロック×はやい×かっこいい」「バラード×ゆっくり×かなしい」で別案を比較する。音色の好み、低音の強さ、打楽器の多さ、言葉と聴感の対応を確認したい。自動検証でこれらの採用判断はしない。

## 実装と保存

- `saezuri/music/image-arrangement.js`：言葉、提案BPM、8案の生成、保存レシピの検証。生成は明示操作時だけ。
- `saezuri/music/accompaniment.js`：保存レシピから演奏イベントを作る。既存の伴奏は従来通り。手動コードは自動進行に重ね、手動進行・リズム・音色等を優先。
- `probe/saezuri/image-mode-controls.js`／`image-mode.css`：3選択を1行、別案を調・小節の行へ配置。既存の試聴・確定・Undoを鍵盤の上へ移す。音符がない時は無効な音符編集欄を隠す。
- `edit-session.js`／`capture-editor-view.js`：伴奏候補の所有を識別し、連続再生成は1つのUndo履歴で差し替える。他の音符・構造・録音候補は先に確定／取消。再生・準備・待機・録音・解析・保存中は操作しない。
- `song-session.js`：既存のチェックポイントへ固定レシピを保存。既存曲の伴奏候補は再開後も差し替え・取消可能。今回の候補の基準だけを復元し、一般の全Undo履歴を永続化する変更はしない。

メロディー、明示的な休符、調、BPM、小節数は生成で変更しない。手動指定は専用の印と既存のコード／音色データで保持する。音符なしの新規候補は採用前には保存枠も再開対象も作らず、採用済みの伴奏だけの作品は従来通り保存する。保存曲数・生音声・ハナウタ詳細データの扱いは変えない。

`imageArrangement.version=1` に和声、弾く位置・向き・長さ・強さ・低音・打楽器・音色を格納する。長調／短調の具体的な進行を両方保存し、利用者が調を変更した時も新しい乱数を使わない。試聴・ループ周回・録音開始・再読み込みでは生成を呼ばない。将来編曲を変更する場合は、旧レシピの演奏互換を保つこと。
