# 録音中の小節・拍とコード進行（2026-10-18）

## 背景と表示

イメージ確定後に空の譜面とコード編集欄を閉じた結果、録音する場所の手掛かりも減っていた。「録音の方は小節の位置がわからない」「コード進行も知りたい」という指摘に対応する。

- 録音操作のすぐ下に、小節番号とコードの細い列を常設する。4小節・8小節とも横送りせず全体を確認でき、現在の小節は明るい黄色と濃い枠で示す。
- 音色の横に「何小節目・何拍目」「今のコード→次のコード」を表示する。タップ録音、ハナウタ、伴奏ループで同じ場所を使う。
- 次の先頭から録る待機中は「次の先頭から：あと○拍」。待っている間も伴奏の実際の小節・拍を追い、先頭で録音中へ切り替える。
- タップは繰り返しの先頭へ戻り、ハナウタの取り込み終了では最終小節を保つ。停止時は現在位置の強調を消す。伴奏なしの場合はコードを推測表示せず「伴奏なし」とする。
- 既存のコード計算を使うため、手動コード、短調、分数コードも同じ表記。小節途中の短いコード区間も「今・次」の切り替えに使う。長い曲は現在小節が見えるよう列だけを送る。
- 自由制作では停止中のコード編集ボタンを保ち、再生・録音中は共通の進行表示へ置き換える。同じコードを2列重ねない。
- 縦の短いスマホでは鍵盤の高さを96〜112pxの間で調整し、文字と録音ボタン・オクターブ操作の場所を確保する。鍵盤以外のボタン間隔8px、下中央の停止を維持する。

空の譜面を戻したり、コード編集を前提にしたりせず、確定後にそのまま録音できる流れを維持する。表示は `recording-guide.js` にまとめ、既存の音の時計・ループ先頭・録音開始時刻を読む。追加タイマーは作らず、小節・拍・コード・状態が変わった時だけ表示を更新する。音源、音の予約、用途別遅延、録音の保存・候補→オッケーは変更しない。
