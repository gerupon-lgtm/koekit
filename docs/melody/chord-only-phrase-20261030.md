# コード進行だけのフレーズ — 2026-10-30

## 指定と動作

コード進行を先に作り、メロディーなしでもフレーズとして登録したい、という指定に対応する。

伴奏をONにし、コード進行を「オッケー」で確定してから「フレーズにする」で登録する。「じゆうにつくる」では「フレーズをつなげる」を開いて操作する。「イメージからつくる」も同じ登録を使う。

音符が1つ以上ある従来の条件に加え、音符がなくても有効な伴奏がONなら登録できる。未確定の編集・録音／再生中・配置編集／配置候補中の登録制限は維持する。音符も伴奏もないもの、伴奏OFF、不正な伴奏だけの登録はできない。

元の4／8小節、調、手動コードと分数ベース、音色、イメージ設定をそのまま複製する。音符を仮追加しない。「つなげる」の配置候補→オッケー、再生、保存・コピー・再読み込み、配置の編集／Undo、エンディングは既存の仕組みを使う。保存形式の変更はない。
