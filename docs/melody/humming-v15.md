# ハナウタ v15：番号で音を選ぶ・スマホで選択音を追う

2026-09-27。v14の操作確認後、発案者は「選択は動くが、どの音か分かりづらい・移動が手間」「10音送るために10回発話するのは現実的でない」と指摘。番号付きブロックを選んでから編集する流れへ改善した。

## 操作

- 各音に、発音順の番号を大きく表示する。譜面のタイで分かれた表示は同じ1音として数える。
- 「10ばん」「10ばんめ」で10番目を直接選ぶ。タッチでは番号ブロックを直接押す。「さいしょ」「さいご」も音声・ボタンの両方で使える。
- 「つぎ／まえ」は隣の音への微調整に残す。端では折り返さず、その方向のボタンを無効にする。
- 選択後は「あげる／さげる」、流れの試聴、まとめてオッケーへ進む。音の選択自体では音列やUndo履歴を変えない。
- 存在しない番号では選択を変えず案内する。分割・結合・削除後の番号は、その時点の発音順に振り直す。音符IDによる編集・Undoとの関連は保つ。

## スマホ表示

操作欄に「10 / 16 ばんめの音・3小節目・音名」を常設。ブロックを五線譜の上へ移し、番号を大きく表示する。選択した符頭の色と輪郭を強め、仮編集の点線とは区別する。

五線譜は高さを制限したスクロール枠に表示する。選択した音へ枠内を自動移動し、横に並ぶ番号ブロックも選択箇所を表示する。編集部分が画面外にある時は、そのまとまりを画面へ戻す。4小節を辿るたびに操作ボタンが遠くへ離れる状態を抑える。

縦画面は操作欄→番号→譜面の順。幅600px以上かつ高さ480px以下の横画面は、操作欄と譜面を左右に置く。詳細入力・解析設定・試作診断は残しており、本アプリ全体のスマホ画面の完成ではない。

## 確認

- Node12件：発音順の番号選択、直接10番へ移動、先頭・末尾・範囲外、数字／漢字／かなの完全一致、仮編集・Undo・音声区間制御。
- Chrome：共通Voskアダプタへ模擬結果を渡し「10番／最後／最初」を確認。320×568、390×844、844×390、1280×800で直接選択・番号タップ・端ボタン・選択音の画面内表示・横のはみ出しなしを確認。
- 日本語の実モデルへWindowsの合成音声を入力し、「じゅうばん」→`十 番`→10番選択、「さいしょ」→`最初`、「さいご」→`最後`を確認。数字語彙は既存deliveryの方式に合わせ、漢数字と「番」を空白で分けて登録する。実際の利用者の発話やスマホのマイク環境の精度は別途確認する。
- v14の録音→3方式→編集→試聴→確定→Undo→終了→再開の回帰も成功。認識器へ渡る語彙と結果処理の検証であり、実声の番号認識精度は次の実機確認事項。

音高検出、実測補正、確定とUndoのルールは変更しない。公開状態は[公開記録](preview-deployment.md)を参照。
