# 曲全体からの制作 Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans task-by-task.

**Goal:** 部品を曲内で作り、全体から配置・コピー・移動・外す操作を行う。現行の見た目を維持し縦の積み重ねを減らして公開する。

**Architecture:** 音源と編集器は再利用。project-sessionは部品別checkpointと旧曲移行、project-workflowは画面と切替、arrangement-gesturesは指操作を担当する。既存SongWorkflowの直列保存と配置候補の確定を維持。

**Tech Stack:** HTML/CSS/ES Modules、IndexedDB、Pointer Events。ビルド追加なし。

**Spec:** project-workflow-20261031.md

## Global Constraints
- 音声外部送信なし。タッチのみで全操作。候補→オッケー／取消を維持。
- 4/8小節、16配置、最大10曲、44px操作と8px間隔。別作品のロジック不変更。
- 旧曲・無音・未確定作業を保護。検証版とキャッシュ識別子を公開ごとに更新。

## Review Focus
- 複数の空部品／候補を切替・再読込しても内容がすり替わらない。
- 同じAの一か所の移動・修正・外すで他のAが変わらない。
- 保存失敗・別タブ競合・10曲上限で既存曲を消さない。
- 長押し前のスクロール、範囲外ドロップ、中断で意図せず配置しない。
- 短画面、文字拡大、録音フォーカス、固定停止欄で操作を見失わない。

## 実装と判断

現行の紙色・丸い文字・ラベンダー／緑のボタンを継承。入口は空の曲全体。トップの「サンプルでためす」はA/B/CとA–B–A–Cを毎回原本から開き、保存枠を使わない。「自分の曲にする」で通常保存へ移す（発案者の追加承認済み）。通常の部品は＋つくるで作成前に独立IDを持ち、別登録なしで途中作業を保持。詳細は[データ設計](project-data-model-20261031.md)。

部品側の「並びに入れる」と、並びの先頭・各カード後の＋を用意。選び直しは1候補を差し替え、試聴・オッケー／取消。長押し→外す／移動→もう一度指で運ぶ。移動中だけ指の移動をカードへ割り当て、通常の縦スクロールと分けた。端の補助は並び枠内に制限し、離す・中断・Escapeで停止する。

一か所修正の保留は全体で再開可能。通常往復のUndoは部品／配置修正ごとに保持する。配置済みの元を保護し、全配置の暗黙上書きは保存層でも防ぐ。旧形式の作業は自動確定せず移行する。
