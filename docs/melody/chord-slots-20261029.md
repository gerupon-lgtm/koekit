# よく使うコードの個人スロット（2026-10-29）

## 合意した内容

プリセット7個（緑）に、個人用9枠（黄色寄りのクリーム）を追加し、プリセット行の空きを含めた4列×4段、合計16個とする。本人が9枠案を選択した。続く指示で、常設のクリアボタンを取りやめ、追加枠の長押しからメニューを開き、別の操作でクリアを確定する形に変更した。

1. 「よくつかう」の空き枠「＋」を押すと「すべて」を開く。ルート・種類・ベースを選び、「よくつかうに登録」で指定枠へ保存する。
2. 「すべて」から直接登録する場合は最初の空き枠を使う。9枠が埋まったら登録を休止し、既存枠を勝手に上書きしない。
3. 登録済み枠の短いタップは、そのコードを選んで試聴する。「このコードをきく」も維持する。
4. 登録済みの黄色い枠を約550ms長押しすると、枠番号・コード名を示す確認メニューを開く。「この枠をクリア」をあらためて押した場合だけ空き枠に戻す。「とじる」やEscapeで取り消せる。PCでは右クリック／Shift+F10からも開ける。
5. 登録・試聴・クリアでは小節のコードを変更しない。曲への反映は「つかう」→最後の「オッケー」のまま。枠を消しても、すでに曲へ使ったコードは残す。

## 配置と保存

- 緑のプリセットは従来の長調／短調別7候補。個人枠は調外のコードと分数コードも保存でき、曲や調が変わっても同じ絶対音程のコードを呼び出す。
- 枠は44px以上、間隔8px、横4列。空き枠も同じ位置・大きさを保つ。「よくつかう／すべて」は同じ高さにし、詳細の開閉によるずれを避ける。
- 常設のクリア行は追加せず、「黄色の枠：＋で登録・長押しでクリア」と表示。確認メニューの閉じるは右上。
- 保存先は端末内の `localStorage`、キー `saezuri.chordSlots.v1`。曲の保存形式・保存枠数・候補・Undoとは独立し、曲をまたいで保持する。位置は詰めず、クリアした場所が空きになる。
- 保存するのはroot・quality・bassのみ。壊れた値を検証し、無効な枠は空きとして扱う。保存に失敗した場合はその画面内だけ利用できることを表示し、曲の保存に影響させない。
- 長押し中の10px超の指移動、指の取消、画面非表示、再生開始、編集終了で待機を取り消す。長押しから指を離した時の互換クリックが、新しく開いた確認ボタンを押してしまうケースをChromeのタッチ入力で再現し、その同じ操作のクリックだけを抑止した。次のタップやキー操作は受け付ける。
- 音源・音量・録音の時計・曲再生の予約方式は変更しない。登録済みコードも既存の短い和音試聴へ接続する。
