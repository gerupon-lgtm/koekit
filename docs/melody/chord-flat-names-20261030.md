# コードネームの♭表記統一 — 2026-10-30

## 合意と変更

ユーザーの選択により、コードのルートと分数コードのベースは `C・D♭・D・E♭・E・F・G♭・G・A♭・A・B♭・B` に統一する。

選択画面とカード／五線譜に混在した独立の表記表を、`saezuri/music/catalog.js` の `CHORD_PITCH_NAMES`／`chordLabel` へまとめた。従来の `image-controls.js` のexportは互換を維持し、コード候補、登録枠、録音中の今／次のコード、エンディングも同じ名前を使う。

カード／試聴の五線譜で省略されていた分数ベースと一部の種類名も、同じ完全なコード名で表示する。`m7♭5` を含む現行13種類に対応する。音符の調号・音名は既存の規則を使う。

保存値は音の番号なので、曲や個人枠の書き換え・移行は行わない。root／quality／bass、鳴らす音程、メロディー、テンポ、候補→つかう→オッケー、保存再開を維持する。
