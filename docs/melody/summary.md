# サエズリズム 基本設計サマリ

2026-10-01／設計v0.3・要件v1.2。保存・再開、伴奏・個別コード・音色、4／8小節ループ録音を実装し、依頼に従い既存試作URLへ公開。[検証と残件](workflow-implementation-plan.md)、[配信記録](preview-deployment.md)。診断のprototypeは互換用にv25を維持し、workflowRevisionで更新を識別する。本アプリの全機能とループ録音実機品質は未完了。

音符がない新規曲のコード候補は、オッケーで決めるまで保存しない。決めた伴奏だけの曲は保存できる。曲数は初期10曲で、後から増やせる。コードの変更画面は1小節単位だが、内部のデータと演奏処理は後の1拍／2拍切替にも備える。ハナウタ確定時に録音の細かなデータを消す範囲は、改めて相談してから実装する。

音名入力とタッチで4〜8小節のメロディを作り、伴奏・音楽支援・五線譜で楽しみ、最大16パーツ＋任意1小節で曲にする。コード進行から作り始めてもよい。従来4小節のハナウタに加え、4／8小節ループ先頭からの録音を検証する。採点は行わない。

## 今回決めた操作

長調（C）／短調（Am）と4／8小節は「つくる」のタブ直下で選ぶ。設定を開く必要はなく、どの制作タブでも同じ位置に並ぶ。変更は候補を聴いてオッケーで決める。8→4小節の短縮では後半を外すことを案内する。

- 伴奏ループ中に録音を指示すると、次のループ先頭から1フレーズ分を録り自動停止。直前の指示でも1周追加せず、残り拍を表示する。
- 伴奏の候補はおすすめ1＋比較3の最大4案。同じ画面ですべて聴いて選べる（2026-10-01画面確認後の変更）。確定後も小節ごとに変更でき、m7♭5を含む13コード種＋分数コードを選べる。
- 生楽器風と電子音を両方用意して混ぜられる。個別指定した音色・コードはジャンル変更で無断リセットしない。
- 音量は「設定」でカウント・伴奏・全体を0〜200%から選ぶ。100%が従来の音量で、全体はメロディー・伴奏・カウントすべてに効く。端末に記憶し、再生中も変更できる。
- 音符がある、または伴奏・コードを明示確定したら保存開始。音符なしの確定伴奏も保存可能。高さ・長さの選択だけはデータ変更なしだが、コード変更は別判定。
- 未確定内容は「つくりかけ」として自動保存。通常終了では保存し、次回その作品を開いた時に「つづきから つくる」／「つくりかけを けす」を選ぶ。不慮の停止も最後に保存できた内容から復帰。
- つくりかけを捨てても確定版は残す。確定版のない新規草稿だけは一覧から取り除き枠を空ける。保存失敗時だけ終了前に再試行／続ける／保存せず終了を確認する。
- 「もどす」の細かい履歴は同じ制作中だけ。終了・再読込後は復元せず、画面切替・試聴中は維持する。

コード選択の下シート方式は**仮採用**。実際のUIを見てから操作性を相談する。具体的な音色・編曲も比較試聴して決める。詳しい操作と確認対象は[伴奏・制作・録音・保存仕様](accompaniment-workflow-spec.md)へまとめている。過去の会話を覚えていなくても、この節から再開できる。

## 設計の要点

- 音符・伴奏・譜面・再生位置を共通の整数時間データで扱う。8分入力と16分取り込みを併存させる。
- 確定版と利用者が作ったつくりかけを別に保存する。試聴・候補復元で勝手に確定しない。
- 配置ごとの編集は選んだパーツだけに反映。同じパーツ全体の変更は対象を見せて一括確定する。
- 音声認識・ハナウタ捕捉・音楽再生を区間管理し、同時にマイクを所有させない。
- 曲は専用IndexedDBへ一体保存。最大10曲、保存世代の比較で古いタブによる上書きを防ぐ。
- メロディの音量はトップから3段階。伴奏音色・各チャンネル音量とミュートは「くわしく」にまとめる。
- 音楽再生の時計を基準に表示し、長時間再生と端末割込みを試験する。
- 初版に共有・書出し・伴奏楽譜・一部分の歌い直しは含めない。

## 実装の順番

1. 音源、譜面、ハナウタを独立試作し実機で比較。
2. 曲データ・編集・保存・タッチ／音声の確定フロー。
3. 再生、伴奏、支援、譜面、パーツ連結。
4. ハナウタ統合、チュートリアル、小鳥単体素材、端末・オフライン検証。

追加ライブラリ・音源素材はまだ選定していない。具体的な品質を見て採用する。共通のビルドなし・外部音声送信なしを維持する。

## 残る確認

詳細・止まる実装範囲は[基本設計11節](design.md)。今回合意済みの操作を聞き直さず、未決の操作だけ、その場で例を説明して確認する。

- Q1は部分合意：上記の保存・つくりかけ・終了・失敗・Undoは確定。残るのは、音符なし・未確定コードだけで保存開始前の場合の草稿枠、練習から作品への登録、原曲／直前版の更新時点、別タブ競合の復帰。
- Q2：候補中の「もどす」は候補取消。「けす」は確認して削除。異なる調はそのまま接続し、おまかせの最後の和音は末尾パターンの調に合わせる。テンポ変更は停止時。
- Q3：画面を離れた・音声割込み・マイクOFFで録音は取り直し、再生は停止。勝手に再開しない。補完や検出失敗の閾値は実機結果で調整。
