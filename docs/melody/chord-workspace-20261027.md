# 制作画面でコードを聴き比べて入れる（2026-10-27）

## 合意した操作

前回の「コードを選ぶと編集候補へ反映」を、本人の使用後の希望により変更する。

1. 制作画面の小節コードを押し、その下の編集欄で候補を選ぶ。この時点では小節を書き換えない。
2. 「このコードをきく」で短く確認する。試聴は任意で、候補・音符・Undo・保存曲を変えない。
3. 「つかう」で対象小節を置き換える編集候補へ反映する。
4. 同じ編集欄の左右ボタン、または上の小節コード列で別の小節へ移動できる。
5. 最後の「オッケー」で、使ったコードをまとめて確定する。まだ「つかう」を押していないローカルな候補は確定に含めない。

小節を移動したら移動先の実際のコードを表示する。未使用候補を別の小節へ持ち越さない。これは誤置換を避けるための実装判断として説明済み。

## 制作画面と高さ

本人が「制作画面内に開く形」を選択し、調の外のコードも選びやすく、縦スクロールが増えすぎないことを追加指定した。

- 通常制作は同じコード編集要素を非モーダルで、小節コード列の直下へ表示する。別画面や背景を覆う表示を使わない。直接の詳細検証画面だけは既存のダイアログを維持する。
- 編集中だけ譜面・鍵盤・制作の詳細設定・フレーズ登録などをたたみ、編集欄を下へ単純に積み足さない。閉じれば元に戻り、曲・表示設定・音色などは変えない。
- 「よくつかう」と「すべて」を同じ高さで切り替える。前者は既存の調別コード候補、後者は全12ルート・既存13種類・全12ベースを横1行の選択欄で扱う。調の外・分数コードも入力できる。
- 既存コードが通常候補にないときは「すべて」を開く。一度選んだ「すべて」は別小節でも維持し、詳細選択の開き直しを減らす。
- ベースがルートと同じ間は、ルート変更に追従する。分数コードのベースを選んだ後はその指定を保持する。
- 現在のコードとまだ使っていない候補を区別して表示する。「つかう」は同じ手動コードを再びUndoへ積まない。
- 小節コード列は1行のまま、選択位置へ横方向だけ追従する。編集中の長いコード名は列で省略し、編集欄と読み上げ用ラベルで全体を確認できる。
- 操作は44px以上、8px以上の間隔。閉じるは右上、停止は制作画面の下中央。再生・録音中は小節・コード編集を休止する。

## 短いコード試聴

前版はコード単独でも曲の再生処理を通り、出力準備と600msの先行待ちを使っていた。

今回は既存の短い音の試聴コントローラーを和音でも共用する。反応優先の音声設定で、準備完了後の音の時計から15ms先へ和音と指定ベースを同時に置く。押すたびに0.4秒の音と自然な余韻を鳴らし、メロディー・ドラム・カウントは鳴らさない。曲全体の安定優先の再生設定は変更しない。

前の試聴や遅れて完了した準備は破棄し、最後に選んだ候補だけを鳴らす。候補変更・小節移動・閉じる・通常再生・鍵盤入力・停止・画面非表示・音声中断では所有する音を停止する。途中で発音に失敗しても作成済みの音を解放する。元の短い単音試聴の挙動は保持する。

15msはアプリが音を置く先の指定であり、操作から耳までの実測値やスマホでの100ms以内を保証する値ではない。初回の音声準備にかかる時間も端末・ブラウザに依存する。

## 2026-10-28 追補：「よくつかう」のコードをタップして聴く
