# フレーズの追加・別曲コピー・保存一覧の再生表示

## 2026-10-30 の合意と操作

当初の発案者構想は短い曲を共通の材料としてつなげる形だった。認識を合わせ、現在の「曲ごとにフレーズと配置を保存する」方法は維持し、追加制作と別曲コピーを実装するよう指定した。全曲共通の保管庫への変更ではない。

- つなげる画面に「曲をえらぶ」「もうひとつ つくる」「ほかの曲から」の3入口を1行に置く。今の曲名も表示する。
- 「曲をえらぶ」は保存曲自体を開き、フレーズと配置を戻して直接つなげる画面へ進む。トップの保存一覧から開く従来の編集開始は維持。コピー・改名後の一覧でも入口の目的を保持する。
- 「もうひとつ つくる」はAを残して作り方を選び、別のBを登録してA→B→Aなどと並べる。登録直後の入口と処理を共用する。
- 「ほかの曲から」は曲とフレーズを選び、聴いて「この曲に追加」。元曲は変更せず材料の一覧へ独立複製する。配置は既存の候補→オッケーを使う。
- 元曲の登録済みフレーズと、未登録でも確定済みの4／8小節を選べる。未確定の音符・コード・連結候補は含めない。確定内容が登録済みと同一なら重複表示しない。
- 音符・開始・長さ・調・コード・伴奏音色・イメージ設定を複製し、新しい識別子を付ける。テンポとメロディー音色は追加先のものを使い、試聴も同じ設定にする。追加先の編集や配置を置換しない。
- 元曲が選択後に変更・削除されたら追加せず案内する。閉じた後の遅い読込結果は破棄。10曲満杯でも既存曲への追加は使えるが、新しい11曲目は作らない。

制作画面に選択欄を増やさず、選ぶ時だけ共通の選択画面を開く。右上「とじる」・下中央「とめる」、44px以上と8px間隔を維持する。

## 保存した曲の再生表示

追加指摘「再生しても表示に変化がない」に対応。準備中／再生中の行、現在小節／全体小節、進行バーを表示し、再生ボタンを「とめる」へ切り替える。

既存の音声時計の位置を使い、16分音符の位置が変わった時だけ表示を更新。別タイマー・音源は増やさない。別曲へ切替、同じボタン、下部停止、閉じる、自然終了、準備中取消、改名／削除／コピーによる一覧更新で状態を戻す。再生では保存内容を変更しない。

## 候補が消える報告

本人指定は「登録→つなげる→左上もどるでサエズリズムのトップ→つなげる」。保存方式とは別で、保持すべき経路である。

変更前の手入力・伴奏だけ・ハナウタ相当の保存曲・おためし編集で各5往復、公開URLでキャッシュ機能有効時も保持した。「もうひとつ」の入口が隠れる問題は新規試験で失敗→成功を確認した。

その後、発案者は「そもそも曲を選んでいないからフレーズも表示されず、保存されないと勘違いしたと思う」と説明した。保存曲と現在の作業の区別、およびつなげる画面から選曲できない導線不足への対応として整理する。データ消失の再現例とは扱わない。「曲をえらぶ」と現在曲名を追加し、未選曲から保存曲を開く実操作を検証する。

トップの「つなげる」にフレーズ／配置数を表示。「記録をコピー」の `arrangement` に版、画面、フレーズ／配置／表示ボタン数、曲ID、保存状態／失敗コード、直近10画面の移動時刻と件数を含める。時刻はISO UTC。既存の端末内コピーだけに含め、情報や音声を自動送信しない。
