# 保存曲一覧の音量と曲の再生レベル（2026-11-01）

## 依頼と決定

保存した曲をトップから聴くときに、深い設定画面を開かずに音量を変えたい。曲はコード単体の確認音より小さく感じるが、コード確認音は現状の大きさが必要との指示。曲の再生レベルを上げ、コード確認音を維持する。

- トップ→「保存した曲をひらく」の下部に「音量」と「とめる」を常時表示する。曲を開かず、再生中も0／50／100／150／200%を選べる。一覧本文だけをスクロールし、下部の高さは増やさない。
- 「曲の音量」は端末共通で記憶し、右上の設定と同期する。曲・並び・音符・Undo・保存枠には含めない。以前の3項目の記録は保持し、新項目だけ100%を初期値とする。
- 曲の標準出力を旧版の2倍（信号振幅）へ上げる。これは体感音量が2倍という意味ではない。メロディーと伴奏の相対バランス・音符・強弱・進行を変えない。
- コード単体の確認は別の出力経路とし、従来の最大3倍補正と伴奏音量・全体音量を維持する。「曲の音量」0%でもコード確認音を消さない。ドンカマ・録音前カウントの出力も維持する。
- 音の経路：メロディー／伴奏→曲音量（基準2倍）→全体→既存ピーク制限。コード確認→全体、カウント→全体。コード確認には従来の伴奏音量を適用する。

ML-004／005／011／016／017、M-S03／05／06の増分。LV-01＝一覧の直接操作、LV-02＝音声経路と旧設定保護、LV-03＝保存・画面・公開回帰。2026-10-01の「3項目・1行・100%は従来値」は今回範囲で置換する。曲ごとのパート別ミックス実装ではない。
