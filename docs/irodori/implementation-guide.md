# イロドリズム 実装指示書（基本設計）

コエキット3本目「**イロドリズム**」＝声とタッチのドット絵/塗り絵**制作**アプリ。この文書は実装AI（Claude Code / Codex）向けの基本設計。**要件は [requirements-irodori.md](../requirements-irodori.md)（v1.5・確定）**、音声実測は [irodori-voice-probe-results.md](../irodori-voice-probe-results.md)。

> **共有文書は変更しない**：`CLAUDE.md`／`AGENTS.md`／`docs/implementation-guide.md`／`docs/tasks.md`／`sw.js` は既存2作品（ピタリズム=`doubutsu/`, メモリズム=`kioku/`）用で Codex が実装中。イロドリズムは**新規ディレクトリ `irodori/`** に作る。共有ファイルへ手を入れる統合作業（SW登録・トップにカード追加）は T-I16 で**別途調整**する。

## 前提（仮置き・実装中に変わり得る【想定】）
- ディレクトリ名 `irodori/`（既存 `doubutsu/`・`kioku/` に倣う）【想定】。
- 盤面サムネは編集データ（cells）から描画し、画像バイナリは保存しない【想定】。
- 見本データの点数・配分は基本設計時の暫定。実装で増減してよい（B区分）。

## 技術スタック（既存2作品と共通・厳守）
- **Vanilla HTML/CSS/JS＋ESモジュール。ビルドなし**（バンドラ/トランスパイラ禁止）。
- 依存は **vosk-browser を自前配置**（`lib/vosk/vosk.js`）のみ。CDN読みしない。
- **共通部品を流用**（新規に作り直さない）：
  - 音声入力層 `src/speech/*`（`VoskAdapter`＝方式C、`vocabulary.js` の正規化・group照合、区間開始/停止）
  - 共通UI `src/ui/*`（カード演出・レベルintro・画面遷移などの再利用可能分）
  - 効果音 `src/audio/*`（正解音・不正解音を流用。イロドリズムでは「確定音」「範囲外の不正解音」に転用）
  - ログ `src/log/*`（任意）
- PWA/SW・キャッシュ方針は既存に準拠（`STATIC_CACHE` に `lib/vosk`/`assets`、それ以外は network-first）。**統合時に `sw.js` へ `irodori/` を追加**（T-I16・共有ファイル変更のため要調整）。

## 守る設計（C区分・合意なしに緩めない）
- **C-1 音声を外部送信しない**（方式Vosk・端末内。方式A=検証専用）。
- **C-2 タッチだけで全機能が操作できる**（マイク未許可でも制作・保存・一覧すべて可能）。
- **C-3 2段階確定**：着色対象（マス/範囲/線）と色を**図示（プレビュー）してから「オーケー」で確定**。誤認識・誤タッチがそのまま塗りにならない。範囲・線・なぞりでも省略しない。
- **C-4 コロガリズム（既存公開作品）に触れない**。
- **C-5 保存データを失わない**：localStorage の保存・呼び出し・再編集を壊さない。上書きで意図せず消さない。消失リスク（サイトデータ削除）に対する復元/持ち出しは将来（NR-11）。
- **C-6 作品の外部共有は将来**（プライバシー設計合意後・NR-10）。本設計スコープ外。

## 変更禁止事項（検証で確定・根拠つき）
実測（[irodori-voice-probe-results.md](../irodori-voice-probe-results.md)）で確定した音声設計。善意の「改善」で緩めない：

1. **全区間 制限文法**（Voskに受け付け語リストを渡す）。自由認識＋変換テーブルは実測で劣る（色89%/英字41%/座標ほぼ0）＝**採用しない**。
2. **座標は「英字→数字」の2トークン（列→行順）**。連結1語（「いちえー」）は認識不可。列→行順はスイープ36/36=100%。数字→英字順（1A）は末尾英字が脱落するため**補助**（許容だが推奨しない）。
3. **英字の読みは複数許容＋精度優先の正読み**：A＝えー/えい/ええ（推奨えい）、**D＝でー**（「ディー」はBに化けるため不採用）、**H＝えっち**、B＝びー、C＝しー、E＝いー、F＝えふ、G＝じー、I＝あい。（`irodori/vocabulary.js` にデータとして持つ）
4. **色は制限文法・12色**。**ちゃいろは「ちゃいろ／茶色／ブラウン」を候補統合**して受ける（単独「ちゃいろ」だけだと きいろ に潰れる＝救済不能）。
5. **確定語＝オーケー**（「けってい」は不可）。**保存語＝ほぞん／せーぶ**。
6. **座標の列に単独「し」を入れない**（数字4=しと衝突）。C は「しー／しい」で受ける。
7. **範囲＝両端含む長方形**。**線＝ブレゼンハム法**で階段状に一意化。範囲外・無効指定は**部分適用せず**、位置を変えず不正解音。

## 音声の区間ステートマシン（`irodori/phase.js` で実装）
制作画面でのみ音声を動かす（タイトル・一覧では区間を開かない）。区間ごとに受け付け語を絞る（C-1/常時認識にしない）：

| 状態 | 受け付け語 | 動作 |
|---|---|---|
| CMD（コマンド待ち） | 座標(列→行2トークン)／移動(方向+数)／色名12／「から」／「せん」／「ほぞん・せーぶ」 | 座標・移動＝カーソル移動。色名＝塗る色を選び対象を確定プレビュー→CONFIRM。「から」＝範囲開始（起点=現在セル）→RANGE。「せん」＝線開始→RANGE。保存語＝保存。 |
| RANGE（範囲/線の終点待ち） | 座標／「まで」／色名 | 終点を決める→色待ち（色名が来ればプレビュー→CONFIRM）。 |
| CONFIRM（確定待ち） | 「オーケー」／別の色名／「やめる」 | オーケー＝着色を確定。別の色名＝色変更。やめる＝取消しCMDへ。 |

- タッチも同じ状態遷移を駆動する（C-2）。ダブルタップ等でマスを直接めくる/塗るショートカットは既存2作の作法に合わせる。
- 各状態のgrammarは `vocabulary.js` の読みテーブルから生成。範囲外座標・移動は現在位置を変えない（不正解音）。
