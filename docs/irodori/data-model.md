# イロドリズム データモデル（localStorage）

保存は **localStorage 一択**（NR-03・C-5）。端末内のみ・外部送信なし（C-1）。画像バイナリでなく**再編集できる編集データ**を持つ。

## キー
| キー | 内容 |
|---|---|
| `irodori:v` | スキーマ版（整数）。マイグレーション判定用。現在 `1`。 |
| `irodori:artworks` | 保存済み作品の配列（JSON）。**最大12件**（NR-03）。 |
| `irodori:draft` | 作業中の自動下書き（単一スロット・JSON or null）。復元用。 |

## Artwork オブジェクト
```jsonc
{
  "id": "a1b2c3",           // 生成ID（衝突しない短い一意値）
  "size": 5,                // 3 | 5 | 7 | 9（size×size のマス）
  "cells": [null, 0, 11, ...], // 長さ size*size。行優先（row-major）。値=色index(0-11) または null(未着色)
  "mode": "free",           // "free"（自由制作）| "template"（見本合わせ）
  "templateId": null,       // template時のみ見本参照（例 "face-5"）
  "createdAt": "2026-09-19T00:00:00Z", // UTC ISO8601
  "updatedAt": "2026-09-19T00:00:00Z"
}
```
- **色は index（0〜11）参照**（軽量化）。index→色定義は `screens.md`「パレット」の並びに一致（コードの単一定義を正とする）。
- **未着色（null）と 白（しろ=index）は別値**（NR/8.7）。完成プレビューは白を見分けられる背景。
- **作品名は持たない**（NR-03。サムネで識別）。
- サムネは cells から都度描画（保存しない）。

## セル座標の対応
- 行 = 1..size（上→下）、列 = A..（左→右、A=0,B=1,…）。
- cells の index = `(row-1) * size + colIndex`。
- 音声「列→行」（例 C3 = 列C・行3）／タッチのどちらでも同じセルを指す。

## 容量
- 最大 12件 × 81マス × 数値 ≒ 数KB。localStorage（目安5MB）に対し余裕。上限到達時は**古い作品を手動削除**（自動削除しない・C-5）。

## 保存の運用（NR-03・確定）
- **手動保存**：制作画面の保存ボタン、または音声「ほぞん／せーぶ」→ `irodori:artworks` に追加/更新。12件超過時は保存不可＋「ふるいさくひんをけしてね」を表示（自動で消さない）。
- **自動下書き**：制作中の変更を `irodori:draft` に随時保存。制作画面を開き直すと下書きがあれば「つづきをつくる？」で復元。手動保存すると下書きはクリア。
- **再編集/複製**（NR-012）：一覧から選び「つづきをつくる」＝同id更新、「コピーしてつくる」＝新idで複製。

## 例外・堅牢性（C-5）
- 読み込み時 JSON パース失敗 → その作品はスキップし壊れたデータで全消ししない。`try/catch` で握る。
- `localStorage` が使えない/満杯（QuotaExceeded）→ 保存失敗を明示（「ほぞんできなかったよ」）、既存データは保持。
- スキーマ版が想定外 → 破壊的変換をせず、読めるものだけ読む。
