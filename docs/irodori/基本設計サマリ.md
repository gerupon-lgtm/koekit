# イロドリズム 基本設計サマリ

声とタッチのドット絵/塗り絵**制作**アプリ（コエキット3本目）。要件 [requirements-irodori.md](../requirements-irodori.md) v1.5 を実装できる形に落とした基本設計。実装指示は同フォルダ [implementation-guide.md](implementation-guide.md)／[data-model.md](data-model.md)／[screens.md](screens.md)／[tasks.md](tasks.md)。

## 全体構成
```
koekit/（既存モノレポ）
├ doubutsu/  ピタリズム（既存・変更しない）
├ kioku/     メモリズム（既存・変更しない）
├ irodori/   ★イロドリズム（新規）index.html, app.js, phase.js, vocabulary.js, board.js, palette.js, storage.js …
├ src/speech/*  音声入力層（流用）  src/ui/* 共通UI（流用）  src/audio/* 効果音（流用）
├ lib/vosk/     Vosk（流用）        sw.js  PWA（統合時に irodori を追加＝要調整）
└ docs/irodori/ 本設計一式
```
- **技術**：Vanilla JS＋ESモジュール・ビルドなし・PWA。既存2作品と同一スタック。依存は自前配置の vosk-browser のみ。
- **新規は `irodori/` に隔離**。既存2作品のコードと Codex 管理の共有文書（CLAUDE/AGENTS/implementation-guide/tasks/sw.js）は変更しない。

## 主要な設計判断と根拠
| 判断 | 内容 | 根拠 |
|---|---|---|
| 画面構成 | モード選択型（じゆうにつくる／おてほんをぬる／さくひん） | 制作ツールとして自然。発案者決定 |
| MVP | 見本・線を含む全機能（将来の共有/持ち出しのみ除外） | 発案者決定 |
| 音声＝全区間制限文法 | 自由認識/変換テーブルは不採用 | 実測：色89%/英字41%/座標ほぼ0で劣る |
| 座標＝列→行2トークン | 英字→数字、連結1語は不可 | スイープ36/36=100%。数字→英字は末尾脱落 |
| 英字の読み | A=えい/D=でー/H=えっち等・複数許容 | 読み比べで D=でぃー→B化けを特定、でー/えっちで解消 |
| 色12色＋茶候補統合 | ちゃいろ/茶色/ブラウンを受ける | 単独ちゃいろは制限文法で きいろ に潰れる |
| 保存＝localStorage | 手動+自動下書き・音声ほぞん/せーぶ・作品名なし・上限12件 | NR-03。編集データで再編集可・軽量 |
| 色＝index参照 | cell=0-11 or null（未着色）、白は別index | 軽量・8.7（未着色と白は別） |
| 線＝ブレゼンハム法 | 45度以外も一意な階段状 | NR-09 |
| 色覚配慮 | 選択色明示＋色名読み上げ＋似た色を離す | NR-07 |

## 検証済みの事実（善意の改善で壊さない）
音声設計はすべて Android 実機で計測（[irodori-voice-probe-results.md](../irodori-voice-probe-results.md)）：座標スイープ36/36=100%、色12色100%、移動+数100%、確定=オーケー、D↔B は D=でー で解消、A脱落は複数読みで解消。
