## T-I05 音声：座標（列→行2トークン）・移動でカーソル（NR-002 / NR-003）
- 完了条件：`irodori/vocabulary.js` に読みテーブル（A=えー/えい/ええ、D=でー、H=えっち…／数字1-9／方向）。`irodori/phase.js` の CMD 状態で **列→行の2トークン**を解釈しカーソル移動。相対移動（方向＋数）。範囲外は不正解音＋位置維持。列に単独「し」を入れない。
- 検証：A1〜（各列×行）でカーソルが正しく動く。「みぎ3」等の移動。**盤面外の座標/移動は動かない**（不正解音）。制限文法（受け付け語リスト）で動く。連結1語は受け付けない。実測読み（実機はT-I17）。

## T-I06 音声：色→プレビュー→「オーケー」確定（NR-004 / 確定語）
- 完了条件：CONFIRM 状態。色名12（ちゃいろは茶色/ブラウン統合）→対象をプレビュー→「オーケー」で確定。別の色名で色変更、「やめる」で取消。
- 検証：**「けってい」では確定しない**（オーケーのみ）。ちゃいろ発話が黄色に化けず茶で確定。確定前は未着色。プレビュー中の色変更が効く。

## T-I07 範囲塗り（NR-005）

- 検証：「AからCまで」等で正しいマス数。逆順指定でも同じ長方形。盤面外を含む指定は塗らない（位置維持）。タッチ（始点→終点）でも同結果。
