## 音声の解釈モデル（発案者と確定・変更禁止：善意の改善で崩さない）
`irodori/vocabulary.js`（読み・文法・解析）＋`app.js` の `interpretVoice`。単一制限文法（制作区間の全語彙）＋トークン解析。全発話・分割発話の両対応。

- **素の座標（列→行）＝カーソル移動＝言い直し（最後が有効）**。連続で言っても範囲にならない（「A1→C2」は C2 の1マス訂正）。
- **範囲**：「座標 **から** 座標（＋色）オッケー」。**「から」で範囲モードに入り、終点＝から以降に最後に言った座標**。**「まで」は省略可**（言っても可）。終点の言い直しは座標を言うだけ。始点の言い直しは「から」を言い直す。
- **線**：範囲指定＋「**せん**」（前後どちらでも）。
- **退化＝キャンセル**：始点+終点が揃わなければ現在マスの1マス（＝「せん」「から」の自然な取り消し）。
- **色**：色名12。**「けす」（けす/けして/なし/無色）＝消しゴム**。
- **オッケー**＝確定（→1マスへ自動復帰）。**保存**＝ほぞん/せーぶ。**やめる**＝やめる/おわり/終わり（タイトルへ・下書きは残る）。**Undo**＝もどす/もどる/まちがえた。**Redo**＝やりなおし。
- 範囲外の座標/移動は**不正解音・位置維持**。
- **英字の教える読み＝A＝えい・D＝でー・H＝えっち**（実機で最も認識されやすい。**限定ではなく**A=えー/えい/ええ、D=でー/で/でぃ、C=しー/しい 等すべて受け付け）。座標の列に**単独「し」は入れない**（数字4=しと衝突）。茶＝ちゃいろ/茶色/ブラウンを候補統合（きいろ潰れ回避）。
