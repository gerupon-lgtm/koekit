## 本作への適用

### イメージカラー

発案者の追加指示は「ロゴの色数を減らし、既存5作品と被らないイメージカラーにする」。5作品のSVG、画像を内包するピタリ・メモリは `assets/brand/PROMPTS.md` と元画像も確認した。全作品の「ズム」は共通の茶色（制作指定 `#88644f`）。

| 作品 | ソース上の接頭部の色 |
|---|---|
| ピタリズム | アプリコット `#df967c`、半濁点はハニー `#e5b85e`（制作指定。SVG内は生成画像） |
| メモリズム | セージ `#8fa58a`（制作指定。SVG内は生成画像） |
| イロドリズム | コーラル `#ec7862`、紫 `#9d6fc4`、青 `#2585c5`、緑 `#4ca38b`、黄 `#f2b544` |
| ジントリズム | 青 `#1969bc`、黄 `#f2b544` |
| サエズリズム | 青紫 `#858fca`、アプリコット `#dfa277`、濁点は薄紫 `#b1a3d6` |
| モノガタリズム | 明るいローズ `#e675a0` を接頭部全体に使用。共通の茶色と合わせて2色 |

紫・青・コーラルは既存と近いため避け、赤紫寄りのローズを選定（Codex提案として実装。2026-09-27に発案者承認済み）。名前・カードの選択枠、選択中の設定文字、物語見出しにも適用。開始・補助・確定ボタンは既存作品と共通の淡い緑・紫・金色を維持し、イメージカラーと操作の役割を両立する。

同日の追加指示「もっと明るめ」に合わせ、ロゴを `#b65378` から `#e675a0` に変更。小さい文字と選択枠は読み取りやすい濃いローズを使用。[名称比較画像](previews/name-comparison.png)で相談したあと、発案者が「モノガタリズム」で再確定した。

### 画面・導線

トップ画面の配置は追加依頼でCSS・SVG・HTMLを再照合した。参照元は `jintori/styles.css` の承認済みタイトル配置、`irodori/styles.css` の2026-09-20承認配置。実測コードは `docs/story/compare-layout.cjs`。

- 通常のロゴ枠上端58px・説明文上端176px・メニュー上端229px・メニュー最大幅420pxは既存と一致。
- ロゴSVGは既存799×196、本作937×196。文字の高さを揃えるため、本作の幅上限を通常446px、画面高819px以下352px、620px以下239pxへ調整（高さは93/74/50px）。狭い画面では左右16pxの余白内へ縦横比を保って縮小する。
- 以前は高さ700px以下で50pxに縮小していたが、ジントリズムの620px以下へ揃えた。320px幅のトップ左右余白は12pxから16pxへ、通常時のフッタ下余白は16pxから8pxへ揃えた。
- 390×844では両ロゴの表示可能幅が358pxで頭打ちになる。7文字の本作は描画高さ約75px、6文字のジントリズムは約88pxとなる。この差は長い名前を1行に収めるためであり、全端末で文字高が同一になるわけではない。
- イロドリズムも高さの切替境界は779px、最小ロゴ高56pxとジントリズムとは異なる。ピタリズム・メモリズムは共通 `styles.css` の別構成。すべての作品が同じ配置値であるとは扱わず、本作はジントリズムを基準にする。

- 素のHTML/CSS/ES Modules、共通の丸い書体を継続。おとなの漢字は既存どおり端末書体。
- ロゴは `story/assets/monogatarhythm.svg`。フォントに依存しない接頭部のSVGパスと、既存SVG内の共通「ズム」を組み合わせた。画像生成APIは使っていない。
- はじめの設定・声の選択を維持。速さ・ためし読みは折りたたみ、検証記録はヘルプ内の保護者向け折りたたみに置く。
- はじめのホームはコエキットへ、名前の戻るは本作のはじめへ、盤面の戻るは前の行へ。めくる直前にもタッチの「もどる」を残す。
- 盤面の終了ボタンは確認を表示する。ヘルプと終了確認中は、聞き取り・読み上げ・3枚選択後の自動進行・めくり後の読み上げ開始待ちを休止する。選択は保持する。
- 物語のあとは「つぎの おはなし」（声は従来の「つぎ」）と「おわり」。終了後や停止後に遅延読み上げを開始しない。
- 高さ700px以下では設定の先頭2項目を横並びにし、盤面のカード高を調整。320×568でも開始・盤面の確定ボタンを画面内に収める。物語本文・詳しい設定は縦スクロールする。
- 発案者の追加指示で共通トップへモノガタリズムのリンクとサエズリズムの「近日公開予定」カードを追加。トップ専用CSSと共通引継ぎも更新。既存作品のコードは維持。デプロイ指示に伴いSW事前キャッシュへ本作とサエズリズムのロゴを追加した。公開確認はデプロイ記録を参照。

## 再生成・確認

ロゴ再生成（素材の再生成用で、アプリのビルド工程ではない）：

```powershell
node docs/story/create-wordmark.cjs
```

自動検査：

```powershell
node scripts/test-story.mjs
python -m http.server 8124 --bind 127.0.0.1
# 別のターミナルで実行。STORY_PLAYWRIGHT はインストール済みモジュールの絶対パス。
$env:STORY_PLAYWRIGHT = 'C:\Users\user\Documents\project\koekit\.local-tools\node_modules\playwright'
node docs/story/verify-ui.cjs
```

検査コードは既存のPlaywrightを読み込むだけで、他作品のファイルは変更しない。アプリの追加依存はない。スクリーンショットは `docs/story/previews/` に保存する。

- 物語6,000通りの検査に成功。
- Chromeで320×568・390×844・768×1024の横はみ出し、開始ボタン位置を確認。
- こども4列・おとな5列、声・タッチ、めくる前の戻る、ヘルプ・終了確認、3枚の自動移動、終了後の読み上げ停止を模擬検査。マイク拒否時のタッチ案内と、読み上げ非対応時も物語まで遊べることを確認。
- 読み上げ・認識は模擬であり、今回の変更のAndroid/iOS実機確認は未実施。番号・名前の聞き取り精度検証も引き続き残る。
