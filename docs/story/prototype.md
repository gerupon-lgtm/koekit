# ものがたり（仮称）試作メモ

> 2026-09-27：要件は[要件定義書](../requirements-story.md)、設計は[基本設計](design.md)を正典とする。本書は試作v1（場面カード連結、現在は `probe/story-v1/`）の記録。盤面版は `story/`。盤面版への変更に伴い、下記の「つながり3段階」は「場面の順番（ふつう／めちゃくちゃ）」に整理された。

置き場所：`probe/story-v1/`（公開メニューには出さない検証用）。開き方：`https://koekit.sikumilab.com/probe/story-v1/`

## ねらい（発案者の回答 2026-09-27）

- まず声なしで物語の仕組みを作り、声はあとから足す
- オフラインのスマホで読み上げ（端末の音声合成）できるかを検証する
- 主人公の名前などを音声入力できると楽しそう（次の段階の候補）
- 並べ方は「場面カードをつなぐ」方式。支離滅裂も面白いかもしれない → つながりの強さを3段階で試せるようにした
- 対象は子ども・大人の両方。モードで切り替え

## 仕組み

- 場面は5段階（はじまり→できごと→ピンチ→かいけつ→おわり）。各段階に5枚ずつ、こども用・おとな用で計50枚（`story-data.js`）
- 文中の `{name}{aite}{basho}{mono}` を差しこみ語で置きかえる
- つながり：しっかり（語を物語全体で固定）／ちょっとへん（語を場面ごとに引き直す）／めちゃくちゃ（段階も順番も無視）
- 場面ごとの「↻」でその場面だけ引き直せる。本文タップでそこから読み上げ
- 読み上げは1文ずつ話す（長い発話が途中で切れる端末があるため）

## 検証の手順

1. オンラインで一度開く（サイト共通の仕組みで、開いたファイルが端末に保存される）
2. 機内モードにして開き直し、「よみあげ」
3. 「オフライン読み上げの検証」欄の記録（開始までの時間・エラー）と声の一覧（端末内か）をコピーして共有

## 未確認・今後

- 【未確認】Pixel 6a / iPhone XR でオフライン時に日本語の声が出るか。Androidは端末の音声データ（Google音声サービスの日本語）が入っていないと出ない可能性がある
- 【未確認】おとなモードの漢字の読み間違い
- 名前の音声入力：Voskの小型モデルは辞書にない名前を認識しにくい見込み。方式の候補は残したまま、実機で試して判断する

## たたき台での方向性（2026-09-27 発案者・仮。相談しながら詰める）

- 読み上げは端末の読み上げ機能（speechSynthesis）を使う。画面でON/OFFを切り替えられるようにする
- オフラインで読み上げできない端末があることは許容する（読めなくても物語は画面で読める）
- 名前の音声入力は「用意した名前の一覧から声で選ぶ」方式（Voskの限定語彙）。自由な名前の音声入力は今回は対象外。1音ずつ組み立てる方式・自由発話の方式は、候補として残す
