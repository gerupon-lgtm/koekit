## 1. どんな作品か

- 裏向きのトランプ風カードの盤面（いつ♠・どこで♥・だれと♦・なにを♣）から、番号を声かタッチで選ぶ。
- 最後の「オッケー」でカードをめくる。選んだ言葉を読み上げたあと、それを使って自動で作った物語を読み上げる。
- 文字が読めない子でも、保護者と一緒に声で遊べることを狙う。おとなモード（漢字あり、1行5枚）もある。
- コエキット（SIKUMI LAB の声とタッチの PWA 集）の1作品。名称は「モノガタリズム」（2026-09-27 発案者確定）。

## 6. 材料の足し方（JSON）

`story/data/kids.json`（こども）・`adult.json`（おとな）の配列に1行足すだけでよい。先頭の `_説明` に同じ内容を書いてある。

| 場所 | 中身 |
|---|---|
| `names` | 主人公の名前の一覧（声で選ぶので、Vosk の辞書にある表記にする） |
| `rows.itsu / basho / aite / mono` | 盤面の候補。`{"w": "言葉", "e": "絵（いまは絵文字）"}` |
| `extras.hito / komono / oto` | 物語の中の脇役・小道具・音。物語ごとに1つ選ばれる |
| `shift.itsu / basho / aite` | 時間が進む・場所が変わる・仲間が加わるときのつなぎ文（同じ物語では重複しにくい） |
| `types` | 流れの型。`"flow": ["はじまり", "できごと", "(よりみち)", …, "おわり"]`。かっこつきは入ったり入らなかったりする。`intro` は物語の前に読む紹介文 |
| `scenes.〇〇` | 場面の文。場面の種類（はじまり・できごと・よりみち・なぞ など）は自由に増やせる。増やしたら `types` の流れで使う |

差しこみ語：`{name}` 主人公、`{itsu}{basho}{aite}{mono}` 盤面で選んだ言葉、`{hito}{komono}{oto}` 脇役・小道具・音、つなぎ文だけ `{new}` 途中から加わる仲間。

約束（`node scripts/test-story.mjs` が自動で確認する）：
- 『はじまり』の文には必ず `{itsu}` と `{basho}` を入れる
- 『できごと』に `{name}`・`{aite}`・`{mono}` を全部含む文を1つ以上置く
- こども用は ひらがな・カタカナだけ（漢字を使わない。共通書体に漢字がないため）
- 使えるのは上の差しこみ語だけ（書き間違い・かっこの閉じ忘れは検査で見つかる）
- 同じ文を2か所に書かない
- 型は、最初が はじまり、最後が おわり、長さは4〜7場面（読み込み時と検査で確認する）

## 9. 実装で分かった注意点

- **読み上げ（speechSynthesis）**
  - 発話オブジェクトへの参照を保持しないと、途中で止まる端末がある（`keep` 配列）。
  - 開始しない・終わらない端末があるため、5秒で打ち切り、文の長さに応じた保険で次へ進む。
  - 長い文は途中で切れる端末があるので、1文ずつ読む（「」の中の句点では切らない）。
- **声の一覧**：Android では遅れて、少しずつ届く。起動直後の一覧で判断しない（`voiceschanged` と0.5秒ごとの再取得）。
- **Vosk**：受付語は区間ごとに文法として渡す。辞書に無い語は認識されない。次の語は辞書に無かった：「よみあげ」「もういっかい」、ひらがなの「たろう」など。
- **画面**
  - 幅320pxでは、列を `minmax(0,1fr)` にしないとはみ出す。
  - マイクのボタンは `position:absolute`（fixed だと盤面に重なる）。
  - おとなモードは、漢字のため端末の丸ゴシックを使う。
- **物語生成**
  - 主人公・だれと・なにを が必ず出るよう、場面を引き直す（最大200回）。それでも出ないときは、3つを含む場面に差しかえる。
  - 途中で加わる仲間は、1人目が登場した場面より後に加える。
