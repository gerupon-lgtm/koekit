## 材料の足し方（JSON）

`story/data/kids.json`（こども）・`adult.json`（おとな）の配列に1行足すだけでよい。先頭の `_説明` に同じ内容を書いてある。

| 場所 | 中身 |
|---|---|
| `names` | 主人公の名前の一覧（声で選ぶので、Vosk の辞書にある表記にする） |
| `rows.itsu / basho / aite / mono` | 盤面の候補。`{"w": "言葉", "e": "絵（いまは絵文字）"}` |
| `extras.hito / komono / oto` | 物語の中の脇役・小道具・音。物語ごとに1つ選ばれる |
| `shift.itsu / basho / aite` | 時間が進む・場所が変わる・仲間が加わるときのつなぎ文（同じ物語では重複しにくい） |
| `scenes.はじまり〜おわり` | 場面の文 |

差しこみ語：`{name}` 主人公、`{itsu}{basho}{aite}{mono}` 盤面で選んだ言葉、`{hito}{komono}{oto}` 脇役・小道具・音、つなぎ文だけ `{new}` 途中から加わる仲間。

約束（`node scripts/test-story.mjs` が自動で確認する）：
- 『はじまり』の文には必ず `{itsu}` と `{basho}` を入れる
- 『できごと』に `{name}`・`{aite}`・`{mono}` を全部含む文を1つ以上置く
- こども用は ひらがな・カタカナだけ（漢字を使わない。共通書体に漢字がないため）
- 使えるのは上の差しこみ語だけ（書き間違い・かっこの閉じ忘れは検査で見つかる）
- 同じ段階に同じ文を重複させない

## 実行と検査

```sh
python -m http.server 8000      # http://localhost:8000/story/ （localhost なのでPCのマイクが使える）
node scripts/test-story.mjs
node scripts/test-logic.cjs
node scripts/check-version.cjs
```

スマホで声を試すには、公開するか、Android の USB 接続＋Chrome のポート転送で `localhost` として開く。

## 守ること（C区分・緩めない設計）

- 公開版で利用者の音声を外部に送らない（端末内Vosk）。タッチだけで全操作できる状態を保つ。
- 番号を聞いただけでは選ばない（光る→「オッケー」）。1回の発話は1語だけ受け付ける。
- 読み上げ中は聞き取りを止める。
- 場面データの約束：はじまりの場面は必ず `{itsu}` と `{basho}` を含む。できごとには `{aite}` と `{mono}` を両方含む場面を1枚以上置く（検査で確認している）。
