## 確定した方向

- 名称は「ジントリズム」。コエキットの独立した小品とする。
- イロドリズムの盤面・座標入力を活用。石ではなくセルの塗りつぶしで陣地を表現し、色と所有者の文字を併用する。
- 音声またはタッチで座標をマークし、確定前の言い直しが可能。「オッケー」で実行。
- 基本色は通常の挟み方を維持し、挟めた全方向を反転する。基本色を弱くする案は撤回。
- 強化色と最強色の両方を設ける。効果は置いた瞬間のみで、盤面に残る強度・耐性を持たせない。
- 4×4・6×6・8×8を使う方向。CPU難易度は「やさしい／ふつう／むずかしい」の3段階で、盤面進行とアイテムの持ち方とは別に扱う（2026-09-20確定）。
- 特殊色の回数は毎局補充が各陣営に強化1・最強1、持ち越しが対戦全体で各陣営に強化3・最強1を初期値とし、後から調整できる設定値にする。設定画面は初版の必須範囲に含めない。
- 特殊色を確定して使ったら、追加の恩恵がなくても消費する方針。

## 特殊色（確定）

- 強化色：通常の全方向反転に加え、置いたセルの上下左右に隣接する相手セルを挟めていなくても反転する。斜めには追加効果なし（2026-09-20発案者合意で確定）。特殊色も通常の合法手に限定する（合意済み）。
- 最強色：自分のセルを飛び越え、その先でも自分のセルで挟めている相手セルを反転する。下記の例を基準にする。
- 右端の◎が〇側の最強色：
  - 〇●〇〇●●●◎ → 〇〇〇〇〇〇〇◎（途中の自分色を越えて左の●も取る）
  - 〇●●●●●●◎ → 〇〇〇〇〇〇〇◎（通常と同じで追加恩恵なし）
  - ●●〇〇●●●◎ → ●●〇〇〇〇〇◎（左端は挟めていないため取れない）
- 最強色は一番多く取れる1方向だけに飛び越えを適用し、それ以外の方向は通常どおり反転する（発案者指定）。全方向に飛び越えを適用する案は採用しない。
- 空白は飛び越えない。方向ごとの「通常に取れる数＋飛び越えた先で取れる数」を比較し、最多の1方向に飛び越えを適用する。同じセルは重複して数えず、ほかの方向は通常どおり反転する。最多が同数ならユーザーが方向を選択できる（合意済み）。助手の「固定順で自動決定」案は撤回。
- 特殊色も通常の挟み込みが成立する合法手に限る（合意済み）。
- 4×4は基本色のみ。6×6・8×8では強化・最強の両方を使用できる。4×4の制限は初期相談の合意を継承し、全サイズで使用可能とした助手の提案は撤回。
- 効果終了後は、置いたセルも取ったセルもその陣営の基本色に揃える。強さ・耐性を盤面へ残さない。

## 色選択と対戦中の操作（確定）

- 開始前に12色（赤・水色・黄色・紫・緑・ピンク・青・オレンジ・黄緑・茶色・白・黒）から、色名の発話またはボタンで選択する。
- ふたりはプレイヤー1→プレイヤー2の順。プレイヤー1の色を「オッケー」または確定ボタンで確定するとプレイヤー2へ進む。同じ色は選べない。CPUの色はユーザーと重ならない色を自動選択する。
- 未選択のまま「スタート」と発話した場合は白／黒。片方のみ選択済みならその色を維持し、未選択側は白／黒のうち重ならない色にする。開始ボタンでも同じ処理を行う。
- 基本色の手順：座標→影響範囲プレビュー→オッケー。
- 特殊色の手順：「きょうか／さいきょう」の発話またはボタン→種類を分かりやすく表示→座標→影響範囲プレビュー→オッケー。選択は1手限りで次の手へ保持しない。
- 最強色の最多方向が同数なら、プレビューに①②…を表示→番号の発話またはタッチで選択→オッケー。番号選択だけでは確定しない。
- 確定前の「もどす」または取消ボタンは、特殊色選択と座標・方向プレビューを取り消す。残数・手番は変えない。確定後の待ったではない。
- 色に加えて所有者を文字で表示する合意を維持する。

## 持ち方・対戦構成

- 「毎局補充」と「対戦全体で持ち越し」は別の選択肢。規定局数の対戦と連勝チャレンジの双方で選べる。
- 毎局補充は両陣営それぞれに強化1回・最強1回。持ち越しは対戦全体で両陣営それぞれに強化3回・最強1回。初期値を設定データで変更可能にする。
- 持ち越しは対戦を通して残数を管理し、使う対局をプレイヤーが選ぶ。使った分を次局・再戦・延長で払い戻さない。
- 対戦レベルと持ち方を別に選べる方向。大人も楽しめる対戦を目指す。
- 同じ端末の二人対戦も扱う。話者識別や通信対戦は前提としない。

- 規定局数の対戦はCPU・ふたり共通で1／3／5局を選ぶ。盤面は4×4／6×6／8×8から選び、最後まで固定。
- 引き分けも1局に数え、全局終了後の勝利数で総合勝敗を決める。総合引き分けなら「引き分けで終了／延長して決着」を選べる。延長はどちらかが1勝するまで。
- 延長でも盤面サイズ・毎局補充／持ち越しの設定を維持する。毎局補充は補充し、持ち越しは残数を維持する。
- 4→6→8と進む連勝チャレンジはCPU専用。ふたり対戦は規定局数の対戦を使う。

## 再戦・連勝記録（2026-09-20・発案者指定）

以下はCPU専用の連勝チャレンジの進行。規定局数の対戦の総合勝敗とは混ぜない。

- 負け・引き分けの場合は同じ盤面サイズで再戦するのを基本とし、やめることもできる。
- 毎局補充モードは各対局の支給規則に従うため、再戦時の残数持ち越しを考慮する必要はない。モード自体を廃止するという意味ではない。
- 持ち越しモードは負け・引き分け後も、その時点で残っている特殊色を引き継ぐ。使用分を再戦時に払い戻さない。
- 記録の主軸を連勝とし、難易度・モードごとに別々の連勝記録を残す。
- 現在の連勝数と最高連勝数を分離する。勝利で現在連勝を加算し、負けで現在連勝をリセット（最高記録は保持）。引き分けは負けとせず、連勝数を維持して再戦する（発案者訂正）。例：2連勝→引き分け→勝利＝3連勝。連勝終了と特殊色の補充は別処理にする。
- 勝利後は4×4→6×6→8×8へ進み、8×8到達後は同サイズで連勝を伸ばす（発案者OK）。
- 中断・再開は下記の自動保存方針に従う。ふたり対戦の連勝チャレンジ・連勝記録は作らない。

## 両陣営の条件とコンピュータ（2026-09-20）

- コンピュータもプレイヤーと同じ特殊色の効果・使用上限・補充／持ち越し条件を適用する（発案者指定）。残数は陣営別に管理し、共同の在庫にはしない。
- 二人対戦でも同じルールを使う。相手がコンピュータか人かによってアイテムの性能を変えない。
- 陣営の基本色は開始前に12色から選択。特殊色は「きょうか／さいきょう」の表示で種類を分かりやすく示す。色だけに依存せず所有者文字も維持する。装飾や配色の細部は実画面で調整する。
- 低難易度のコンピュータは、特殊色の追加効果による恩恵を評価せずに使用する。「有効でないので控える」「初心者だから使用しない」という設計にはしない（発案者明示）。
- 実装案：合法手の選択と、残数のある基本色／特殊色の選択を分ける。低難易度では追加反転枚数や有利さを特殊色の選択条件に使わない。使用頻度の具体値は未確定。
- 追加恩恵がなくても特殊色で確定したら消費するルールはコンピュータにも適用する。
- 高難易度は効果・残数・今後の局面を評価する方向。具体的な探索・評価は今後設計する。

## 途中状態の自動保存（2026-09-20・発案者指定）

- 途中状態を自動保存し、次回プレイ時に「続きから」で再開できるようにする。
- モード・CPU難易度ごとに途中状態を持つ。別モード・別難易度を始めても既存の途中状態を失わない。同じ枠では最新の1件のみで、盤面サイズ・局数ごとには保存を増やさない。
- 途中状態がある場合も「新しく始める」を選べる。
- 正しい終了手順で明示的に終了した場合、そのモードの途中保存を削除する（発案者指定）。次回、その終了済みプレイの「続きから」は表示しない。
- 他モードの途中保存は削除しない。最高連勝記録も途中保存とは分離して保持する。
- 自動保存は予期しない中断・ページを閉じる等からの復帰用として残す。ページの非表示・離脱だけを正式な終了とみなして削除しない。
- 終了時は進行中のコンピュータ処理・演出・自動保存の予約を停止し、削除後に古い処理が途中保存を復活させないようにする。具体的な終了UIは実装時に明示する。
- 保存対象には盤面・手番・盤面サイズ・対戦条件・各陣営の特殊色残数・現在の連勝・対局進行状態を含める。
- 設計案：手の確定・アイテム消費・手番更新をひとまとまりとして保存する。再開時に同じ手を二重実行したりアイテムを二重消費したりしない。コンピュータの手番で中断した場合も再開可能にする。
- 設計案：最高連勝記録は途中状態から分離し、新規開始でも保持する。
- 保存があれば「続きから／新規」を選ぶ。新規は同じモード・難易度の途中状態を置き換える。追加の置換確認を合意済み仕様として要求しない。具体的な枠IDは基本設計書7節の設計判断を参照。
- メニューのボタンを増やしすぎない方針を維持し、選択中モードに途中状態がある場合だけ再開導線を表示する案。

## メニューの方向

大きな入口ボタンを増やさず、現在のメモリズムと同程度の密度にする。

- 上段切替：コンピュータ／ふたり。
- CPUでは規定局数の対戦／連勝チャレンジを選択。ふたりは規定局数の対戦。
- 規定局数は1／3／5局と固定盤面サイズを選ぶ。両構成で毎局補充／持ち越しを選べる。4×4では特殊色を使用できないと案内する。
- CPU難易度3段階を大きなボタンで選択する配置案。盤面進行は難易度と別に扱う（旧・盤面サイズと強さをまとめる案を更新）。
- 上記の対戦構成は確定。配置は実画面で検証し、メモリズム程度の密度を維持する。

## 先攻決定（2026-09-20・発案者指定）

- ピタリズムの音声サイコロを活用し、ランダムな出目で先攻を決める。
- 奇数はユーザー（プレイヤー1）、偶数はCPU（ふたり対戦ではプレイヤー2）が先攻。
- 初局のユーザー固定先手案は撤回。初局のみ音声サイコロで決め、次局・再戦は勝敗によらず先後を交代する（発案者指定）。サイコロは振り直さない。
