# コエキットのロゴとシリーズ設計

2026-09-18。発案者との会話で確定した名称・制作方針。

## 名前の構造

- 親ブランド：**コエキット**。ロゴアイコンを持つ。
- 小品：**ピタリ + ズム**、**メモリ + ズム**。文字ベースのロゴのみ。
- 今後の小品も「個別名 + ズム」。先頭の個別名で遊びの個性を、共通の「ズム」でシリーズへの所属を伝える。
- `doubutsu/` と `kioku/` は公開済みリンクの互換性のため維持する。画面・読み上げ・文書には正式名称を使う。

## 共通と個性

「ズム」は作品ごとに描き直さず、同じ画像部品を共用する。字形、色、濁点、字間、サイズを共通にする。個別名は同じ太さ・丸み・ベースラインを守りながら、遊びの性格に合わせて形と色を変える。

- ズム：温かいココアブラウン。落ち着いた丸みと開いたふところ。
- ピタリ：アプリコットとハニー。ぴたりと組み合う安定した形。
- メモリ：やわらかなセージ。記憶をたどるような穏やかな曲線。

強い紺、虹色の塗り分け、影や立体加工は文字ロゴに使わない。小さくしても読める形を優先する。小品ごとの独立したアイコンは追加しない。

## 素材と利用

画像生成は組み込み `image_gen` を使用。原画像を保存し、配信用の軽量版を作る。文字ロゴは共有末尾と個別接頭部から書き出す。画面の画像には作品名の代替テキストを付ける。

ゲームの盤面・操作色はロゴと別の役割を持つため、今回の文字ロゴの配色変更だけで操作色を変更しない。

### ファイル

- `assets/brand/koekit-symbol.png`：生成原画像。画面では軽量版 `.webp` を使用。
- `assets/icons/koekit-180.png`／`koekit-192.png`／`koekit-512.png`／`koekit-maskable-512.png`：PWA・Appleタッチ・ブラウザ用。小品にも親ブランドの同じアイコンを使う。
- `assets/brand/components/{pitari,memori,zum}.png`：採用した文字部品の原画像。
- 同ディレクトリの `.webp` と `layout.json`：配信用部品と透明余白を除いた配置寸法。
- `assets/brand/{pitarhythm,memorhythm}.svg`：配布・表示用の一体ロゴ。WebP画像を内包するSVGであり、字形そのものをパス化したベクターデータではない。どちらも共通「ズム」を同じ位置・倍率で含む。
- `scripts/export-wordmarks.cjs`：上記SVGの再書き出し。通常起動・デプロイに実行は不要（アプリのビルド工程ではない）。新作を追加するときはこの仕組みと共通ズムを再利用する。
- `assets/brand/PROMPTS.md`：採用素材の生成プロンプト。試作・誤字のあった画像は公開対象に含めない。

### 確認

Chromeの390×844／360×640で一覧・両タイトル・案内への遷移、画像の読み込み、横はみ出しなしを確認。manifest記載のアイコン寸法も確認。ホーム画面へのインストール後のアイコン更新は端末側のキャッシュ・再インストールに依存するため、スマートフォン実機で別途確認する。

## イロドリズム（2026-09-19）

- 個別名「イロドリ」は4文字。やわらかなコーラルとサンドを使った丸いベクター筆画。「ロ」の中の1マスでドット絵を表す。独立アイコンは作らない。
- 末尾「ズム」は既存2作品と同一部品・同一倍率。4文字に合わせた838×196のSVGを `assets/brand/irodorhythm.svg` へ出力。
- `scripts/export-wordmarks.cjs` で再生成可能。既存2作の出力は変更しない。トップと制作アプリのタイトルで共用。

## デリバリズム（2026-09-26、素材制作済み）

- 正式名は「デリバリ＋ズム」。2026-09-26の試遊で青緑の「デリバリ」を採用し、その後ジントリズムに近い丸い筆画と濃い茶色の「ズム」へ調整。透明素材を使用する。既存作品のロゴ素材は変更しない。配置と制作方法は[素材記録](delivery/assets.md)を参照。
- キャラクターは比較B案の二足歩行ロボット。荷物0個／片手1個／両手2個を表示する。小品専用の独立アイコンは追加しない。
- ゲーム内表示と音は[基本設計](delivery/design.md)を参照。素材の本制作・ローカル実装済み。[制作記録](delivery/assets.md)に原本・プロンプト・変換条件を記載。
