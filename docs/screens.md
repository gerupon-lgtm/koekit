# 画面設計

## 1. デザイントークン

**フォント・アイコンの定義はこの節が唯一の正典。** 実装指示書には転記しない。

### 2026-09-18 UI更新（A区分・現行）

- 背景 `#f2f6fb`、本文 `#223c60`、開始操作 `#284f85`、カード `#f4c64e`、確定操作 `#16816e`、補助文字 `#5c6e83`。白い盤面と立体感のある札で操作対象を分ける。
- 一覧・タイトルは文字ロゴ（ピタリ＋共通ズム／メモリ＋共通ズム）を使う。コエキットのみ吹き出しと組み立てパーツをモチーフにしたアイコンを持つ。文字ロゴはアプリコット／セージ＋共通のココアブラウンで、詳細は `brand.md`。選択中は緑枠とチェックの形を併用し、色だけに頼らない。子ども向けゲーム中の文字なし方針は維持する。
- 開始案内は `src/ui/levelintro.js` の共通ビュー。ネイティブ `dialog` で背面へのタッチ・フォーカス移動を防ぐ。戻る／Escapeはタイトルへ戻り、開始ボタンで従来のスタート待ちへ進む。
- 案内はレベル配置、登録済みの位置語、操作の順序、保護者向けタッチ操作説明で構成する。「オーケー」を主表記とし「オッケー」も案内する。どちらも既存 `SYNONYMS.confirm` に登録済み。「決定／けってい」も認識語として残す（語彙・判定の変更なし）。
- 表示する位置語は `LEVELS.vocab` と `SYNONYMS` を参照する。中央は「まんなか」を表示する。
- 最小タップ領域48px、可変画面高（svh）、短い画面での案内のコンパクト表示と内部スクロール、キーボードフォーカス表示、`prefers-reduced-motion` に対応。
- 2段階確定、認識区間、ゲームオーバー、レベル構成、秒数は変更しない。以下の旧画面記述にある「矢印」「けってい」などの表示は、この現行UI記述を優先する。

### フォント（確定）

```css
:root {
  --font-family: "M PLUS Rounded 1c", "Hiragino Maru Gothic ProN",
                 "Yu Gothic UI", "Meiryo", sans-serif;
}
```

- **配信: woff2 を `assets/fonts/` に自前配置。** Google Fonts CDNは使わない（オフライン対応のため）
- **サブセット化する。** 使う文字は限られる（バージョン表記・コピーライト・数字のみ。ゲーム画面に文字はない）
- 使用ウェイト: 400 / 700 の2種**【想定】**
- **`font-family` は必ず指定する。** 無指定でOS依存の `sans-serif` に任せない

### アイコン（【想定】・見直しタスクあり）

- **アイコンライブラリを使わない。** 矢印・中点・マイクをインラインSVGで自作する
- 根拠: 画面に文字を使わない方針のため必要な図形が少なく、ライブラリを入れる利点が小さい
- **要件R-06（SIKUMI LAB他作品との統一）が未確定。正式名称の決定後に見直す**（T-030）
- **アイコンライブラリの混在は禁止。** 後から導入する場合は1種に統一する

### 基準値【想定】

| 項目 | 値 |
|---|---|
| 基準サイズ | 16px |
| 行間 | 1.6 |
| タップ領域 | 最小 48×48px（未就学児が操作するため大きめ） |
| カード最小サイズ | 88×88px |
| 矢印の表示サイズ | 画面短辺の30%以上 |

### 画像

- **動物の絵は縦横比を維持する。引き伸ばしを禁止する**（`object-fit: contain`）
- トリミングは行わない（全体表示）

## 5. 受け付け状態の表示（F-003）

**文字を使わず、話していい状態かを示す。**

| 状態 | 表示【想定】 |
|---|---|
| 受け付け中 | マイクの図形が発光し、画面の枠が色付く |
| 受け付け停止中 | マイクの図形が暗く、枠が無色 |
| マイク未許可 | マイクの図形に斜線。**指のアイコンを表示してタッチで遊べることを示す** |
| 認識セッション再開中 | マイクの図形が点滅**【想定】** |

表現は**要件0章のA区分**（実装時に変更してよい）。
