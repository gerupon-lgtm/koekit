## どうぶつめくり（仮称）

音声で位置を指定して裏向きカードをめくる、未就学児向けの知育アプリ。左右→上下→中央→斜め→9枚と段階的に進み、位置を表す言葉を覚える。

**音声とタッチのどちらでも遊べる。** マイクを許可しなくても操作できる。

## 開発フェーズ

- **フェーズ0（関門）** — 音声ルーレット単体で認識精度を計測する。合格ラインを通過しなければフェーズ1へ進まない
- **フェーズ1** — レベル1〜5・認定書・延長ステージ
