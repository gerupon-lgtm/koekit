# モノガタリズム（仮称）— Codex 向け入口（`story/` 専用）

このファイルは `story/` 以下の作業に適用する。リポジトリ直下の `AGENTS.md`（コエキット共通）と併せて読む。食い違う場合、本作の範囲ではこのファイルと本作の文書を優先する。

**着手前に [`docs/story/handoff.md`](../docs/story/handoff.md)（Claude → Codex 引継ぎ、2026-09-27 時点）を読むこと。**

## 最初に読む順

1. `docs/story/handoff.md` — 現状・ファイルの役割・未完了・進め方
2. `docs/requirements-story.md` — 要件。**0章の A/B/C 区分を必ず読む**
3. `docs/story/design.md` — 基本設計（4節 音声受付表、5節 状態遷移、6節 物語の生成規則、9〜10節 タスクと実装状況、13節 並行作業との分離）
4. `docs/implementation-guide.md` 5節・6節 — コエキット共通の変更禁止事項と音声入力層

## 押さえる4点

1. **A 区分は発案者の指示どおりすぐ変える。** 画面配置・文言・色・カードの見た目・物語の材料（JSON）など。文書更新を着手条件にしない。旧記述と違うことだけを理由に指示を断らない。B 区分は変えてよいが、要件の該当箇所と改訂履歴へ1行書く
2. **C 区分は合意なしに変えない。** 利用者の音声を外部に送らない（端末内 Vosk）／タッチだけで全操作できる／2段階確定（本作では「番号はその場で選択 → カテゴリごとにオッケー（3つで自動）→ めくる前のオッケーで確定。めくるまでは もどる で直せる」）／コロガリズムのコードを変えない
3. **触ってよい範囲は本作のファイルだけ。** `story/`・`docs/story/`・`docs/requirements-story.md`・`scripts/test-story.mjs`・`probe/story-v1/`。共通コード（`src/`・`sw.js`・トップの `index.html`・`version.json`）と共通文書は、発案者が統合（MG-T08）を指示するまで変えない。サエズリズム等が並行して同じリポジトリを使っている
4. **前任のコードを作り直さない。** 動いている仕組み（1文ずつの読み上げと打ち切り、区間ごとの聞き取り、読み上げ中はマイク停止、生成の約束）は検証と相談を経た形。善意の「改善」で緩めない

## 作業の決まり

- ビルド工程を入れない（素の HTML/CSS/JS、ES Modules）。追加ライブラリ・サーバー・保存/共有機能を入れない
- 変更後は `node scripts/test-story.mjs` を通す。画面を変えたら幅 320px 前後のスマホ幅で崩れないことを確かめる
- 声で受け付ける語を足すときは、Vosk 辞書（`model/graph/words.txt`）にあるか確かめる（例：「よみあげ」は辞書にない）
- こども用の文字は ひらがな・カタカナだけ（共通書体に漢字がない）
- 設定の保存は `localStorage` の `koekit.story.settings` だけ。読み書きは try/catch で囲む
- 判断したことは会話に残さず `docs/` に書く（要件の改訂履歴、基本設計の実装状況）
- 発案者への説明は、平易な日本語で「なぜそうなるか」を先に、確認済みと推測を分けて書く。技術的に難しいことは進言してよいが、検証範囲から勝手に外さない
